## Use case

Embed a fetched PR title into a generated HTML page.

## Mechanism

Encoding follows the receiving parser; different contexts require different protections.

## Bad example

```text
html = '<h1>' + title + '</h1>'; also interpolate title into a script string.
```

## Good example

```text
For visible text, assign textContent or use HTML text escaping. For JSON state, serialize safely and neutralize script termination through the renderer's supported helper. Do not reuse HTML escaping as JavaScript-string escaping.
```

## Why the change matters

Encoding follows the receiving parser; different contexts require different protections.

## Observable expectation

A title containing </script> displays as data and never executes markup.

## Limits

Use vetted framework encoders and test actual insertion contexts; sanitization is not a universal function.
