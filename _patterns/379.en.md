> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A team uses an agent host without slash-skill installation; copying every workflow into project context is expensive and can imply tools the host lacks.

## Mechanism

Branch on host capability. Install the full suite where supported; otherwise offer a generated, byte-bounded digest of stable ethos, reuse rules and voice. Label it instruction-only, state which workflows require the full suite, include a visible version, and let the user copy it into a file the host actually reads without overwriting existing instructions.

## Bad example

```text
Paste a short digest and tell the agent to run review, QA and deployment skills it cannot access.
```

## Good example

```text
This host only reads project instructions, so offer the versioned 2 KB rules digest for user-controlled copy. State that it provides behavioral guidance only; link the complete suite for review, QA and deployment workflows.
```

## Why the change matters

A portable behavioral baseline carries shared rules across hosts without implying access to missing tools or workflows.

## Observable expectation

The host receives only guidance it can follow, existing user instructions stay intact, and the route to full capabilities remains clear.

## Limits

A digest does not supply tools, invocation schemas, multi-step workflows or evaluations. Confirm the target file is loaded; regenerate and recopy after upgrades. Its byte cap does not measure total session context.
