> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Cache a localized per-tenant report.

## Mechanism

Inventory tenant, viewer permissions, locale and feature state; state staleness/invalidation explicitly and reject reuse across unmatched response contexts.

## Bad example

```text
Key only by the report URL and serve the first cached user result to everyone.
```

## Good example

```text
Key by report version, tenant, locale and authorization context; require a stated freshness policy before reusing a response.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

A speed improvement does not erase response identity or confidentiality boundaries.

## Limits

A complete key can be expensive or unstable; verify the actual dependency set and avoid caching freshness-critical data.
