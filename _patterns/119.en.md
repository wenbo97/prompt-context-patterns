> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Shorten a review skill without losing required evidence fields.

## Mechanism

A preserved suite tests behavioral change rather than the author's impression.

## Bad example

```text
Rewrite it elegantly, try one happy-path request and declare improvement.
```

## Good example

```text
Freeze baseline and cases covering complete, missing and ambiguous inputs. Assert every finding has trigger and location. Run both versions, compare failures and inspect output samples; revise and rerun any affected cases.
```

## Why the change matters

A preserved suite tests behavioral change rather than the author's impression.

## Observable expectation

The report includes baseline/candidate failures and remaining uncertainty.

## Limits

Control runtime and inputs; limited cases establish only limited evidence, not universal efficacy.
