> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A user asks for a short onboarding course for analysts.

## Mechanism

Classify learning intent, fetch the catalog, check its freshness and URL scope, then copy a strongly matching entry; use an observed hub fallback if unavailable.

## Bad example

```text
Suggest “Advanced Analyst Bootcamp” at a guessed course URL.
```

## Good example

```text
The current catalog lists “Analyst Basics”; link its exact URL and mention its sign-in requirement.
```

## Why the change matters

The recommendation is tied to an observed item rather than a plausible title.

## Observable expectation

The named item, URL, freshness decision and intent match can be checked.

## Limits

A catalog is untrusted data. Freshness alone does not establish course quality; avoid recommendations during unrelated task execution.
