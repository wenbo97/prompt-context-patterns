> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A context tool returns success after writing a design decision to a different selected corpus.

## Mechanism

Capture the effective target before the write, use that same target for a fresh readback, and compare the returned substantive content. Keep command success and verified target content as separate outcomes.

## Bad example

```text
The save command exited zero. Report that the decision is available in the team corpus without reading it back.
```

## Good example

```text
Save this decision in the authorized team corpus. Record the effective account, source and storage target; do not infer the engine from a source pin. Read the saved page back from that same target and compare its title and decision content. If the target changed, the read failed or the content differs, retain the decision and report the save as unverified.
```

## Why the change matters

A successful command can reach an unintended corpus; target identity and matching readback expose that mismatch.

## Observable expectation

The report identifies the verified target and matching content, or names an unverified save without losing the local decision.

## Limits

A fresh readback does not prove crash durability, replication or future retrieval ranking. Trustworthy target metadata and read semantics are required; the operation remains limited to the user-authorized destination.
