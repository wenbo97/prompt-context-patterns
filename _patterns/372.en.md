> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A Write request replaces an existing10-line note with900 lines under a local800-line policy.

## Mechanism

Parse the proposed tool input, require the expected field and type, apply the policy to that content, and return a rejection through the verified pre-execution hook contract when it fails.

## Bad example

```text
Count lines in the current10-line disk file, allow the request, and discover the900-line replacement only after writing.
```

## Good example

```text
Count900 lines in tool_input.content before execution and reject this request; treat missing or non-string content as an invalid request rather than an empty file.
```

## Why the change matters

The old file describes current state, while the policy governs the requested new state.

## Observable expectation

The oversized replacement is rejected before mutation, and the existing note remains unchanged.

## Limits

The800-line threshold is only this teaching policy. Hook registration and blocking status must be verified in the actual host; edits, binary writes and other mutation paths need appropriate proposed-state validation too.
