> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Optimize a slow list rendering path.

## Mechanism

Record idea, baseline/result, verdict and reason; consult that ledger before retrying the same proposal.

## Bad example

```text
Delete the reverted memoization attempt and propose it again next session.
```

## Good example

```text
Record memoization unchanged within noise, with workload and result; test virtualization next and link its accepted evidence.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

A later agent can distinguish unexplored ideas from already rejected ones.

## Limits

New workloads or code may justify repeating an old idea; qualify the recorded context rather than treating rejection as permanent truth.
