> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Modernize a working checkout page.

## Mechanism

Detect preserve versus overhaul, record brand/content/routes/tracking/accessibility, then apply focused visual changes within that contract.

## Bad example

```text
Replace the layout, field names and route slugs while restyling.
```

## Good example

```text
Audit checkout routes, event names, field identity and focus behavior; restyle spacing and typography while preserving those contracts.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

Visual changes can be reviewed separately from accidental behavior/identity drift.

## Limits

Explicitly authorized structural changes require their own migration and verification, not blanket preservation.
