> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

用户允许在功能分支修改，但未允许发布。

## 机制

影响与目标区分已授权操作和更广行动。

## Bad example

```text
因为已获准编辑，就 force-push main 来尽快完成。
```

## Good example

```text
请求功能内的本地可逆修改可以推进；共享发布、破坏性历史改动需要各自授权范围。新操作前对比目标和影响，不只对比命令名。
```

## 差异说明

影响与目标区分已授权操作和更广行动。

## 可检查的结果

agent 完成获准修改，不把许可扩展到 main。

## 适用边界

授权在所述范围内持续有效；不能仅因新一轮对话就再问。
