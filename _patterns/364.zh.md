> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

代理处理两个约定不同的仓库，并共享团队交接。

## 机制

搜索项目与团队范围，显式申请用户范围；把记忆正文当作待核实证据。

## Bad example

```text
因为匹配度高，就将私人全局“使用 React hooks”记忆套到 Python 服务。
```

## Good example

```text
读取 Python 仓库的团队决策，与当前代码核对，排除私人和其他项目记忆。
```

## 差异说明

检索命中只有符合任务范围与当前事实才可采用。

## 可检查的结果

交接说明所选记忆范围及核实来源。

## 适用边界

路由标签不等于身份认证；检索被拒绝时不能扩大范围绕过。
