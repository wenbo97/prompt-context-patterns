> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An authorized history rewrite must protect the current branch and local files.

## Mechanism

History refs and working-file backups protect different state.

## Bad example

```text
Create a tag, then assume every local file can be restored.
```

## Good example

```text
Record HEAD and create a recovery ref. Separately back up tracked diffs and untracked files. Verify both recoverable artifacts before the authorized rewrite; report their paths and restoration procedure.
```

## Why the change matters

History refs and working-file backups protect different state.

## Observable expectation

Recovery covers the recorded commit plus the observed dirty files.

## Limits

Tags do not save uncommitted data, and recovery artifacts do not grant permission to destroy.
