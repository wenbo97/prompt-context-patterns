> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Send an incident summary to an external support service.

## Mechanism

The destination rule is attached to data meaning, not the source tool's reputation.

## Bad example

```text
Send the incident because it is an internal tool response.
```

## Good example

```text
Apply the supplied policy: public status is shareable; customer payload is restricted. Extract public status and aggregate counts only. If classification is unknown, withhold transfer and report the unresolved fields.
```

## Why the change matters

The destination rule is attached to data meaning, not the source tool's reputation.

## Observable expectation

The outbound payload contains only fields allowed by the supplied matrix.

## Limits

This illustrates a local policy, not universal legal or provider permission.
