> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Generate queries for a supplied deployment schema.

## Mechanism

Explicit facts supply the names and meaning the task requires.

## Bad example

```text
Find active blocked deployments using suitable columns.
```

## Good example

```text
Schema v2: active when is_deleted=false; blocking types are halt and block_all. Query those exact fields for the supplied table. If the live schema differs, stop and report the mismatch.
```

## Why the change matters

Explicit facts supply the names and meaning the task requires.

## Observable expectation

The query uses supplied columns and values without fabricated fields.

## Limits

Large or changing domain material belongs in versioned references, not permanent prompt copies.
