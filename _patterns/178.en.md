> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A pattern index is generated from metadata and bilingual pages.

## Mechanism

Fingerprints identify content changes even when copy operations preserve timestamps.

## Bad example

```text
Use modification timestamps alone to assume the copied index is current.
```

## Good example

```text
Store hashes of metadata and page inputs with the generated index. Before serving or evaluating it, recompute those hashes. Any mismatch requires regeneration and validation; publish only after the derivation chain matches.
```

## Why the change matters

Fingerprints identify content changes even when copy operations preserve timestamps.

## Observable expectation

Changing one upstream page invalidates the index's recorded inputs.

## Limits

Document all meaningful dependencies, including generator version and relevant configuration.
