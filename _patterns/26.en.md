> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Explain why requests returned 503 during a database outage.

## Mechanism

A trace separates observed facts from interpretation and uncertainty.

## Bad example

```text
The database probably failed; mark the root cause confirmed.
```

## Good example

```text
Claim: DB disconnect caused 503. Evidence: request r17 log at 12:04 reports db_disconnect; handler.ts:42 maps that error to 503. List unavailable database metrics and label cause provisional until alternate paths are excluded.
```

## Why the change matters

A trace separates observed facts from interpretation and uncertainty.

## Observable expectation

A reviewer can inspect both cited artifacts and the missing-input list.

## Limits

Evidence supports only the stated scope; perceived confidence is not a calibrated probability.
