> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Compute token usage between observations 100, 140 and 200 from a cumulative counter.

## Mechanism

Record semantics, units and interval boundaries; difference cumulative values for the interval and preserve missing observations as unknown.

## Bad example

```text
Add 100+140+200 and report 440 tokens used during that interval.
```

## Good example

```text
For the interval after the 100 baseline, report 200-100=100 tokens; do not assign unobserved per-turn values when an intermediate record is missing.
```

## Why the change matters

Cumulative samples repeat earlier usage and cannot be summed as independent increments.

## Observable expectation

The calculation names the counter type, unit, baseline and supported interval total.

## Limits

Counter resets and parent/child attribution require explicit handling; missing data is not zero. For cumulative usage snapshots, aggregate final cumulative totals once per declared invocation rather than summing each repeated snapshot as a new interval.
