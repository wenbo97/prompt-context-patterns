> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Determine which skill version influenced a session recorded last month.

## Mechanism

Use captured bodies/archives for historical claims, current checkout for present observations, and label unresolved version fields explicitly.

## Bad example

```text
Use today’s HEAD as proof of the version loaded last month.
```

## Good example

```text
Cite the captured skill body and its hash for last month; label today’s checkout separately; leave uncaptured installation version unknown.
```

## Why the change matters

Current state cannot authenticate past state, and one captured file cannot prove an entire installation.

## Observable expectation

Every version field has a time/provenance label and supporting location.

## Limits

Preserved copies may be valid evidence even if original paths are gone; verify their provenance. Keep retrieved_at distinct from the source observation time; a response received today does not make cached or undated evidence current.
