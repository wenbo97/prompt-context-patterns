> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A review agent may read sources but cannot publish or alter production.

## Mechanism

The classification connects intent to an enforceable capability decision.

## Bad example

```text
Allow every action unless the agent feels it is unsafe.
```

## Good example

```text
Policy: read source → allow; post review → require scoped approval; production mutation → deny. Enforce at the tool layer including shell and network routes. A denied action reports the policy reason; it is not retried through another tool.
```

## Why the change matters

The classification connects intent to an enforceable capability decision.

## Observable expectation

A denied production write stays denied through alternate execution paths.

## Limits

Choose the policy for the deployment; arbitrary hook text must not become user authorization.
