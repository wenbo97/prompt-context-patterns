> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Hand eight page sections to a coding agent.

## Mechanism

Count requested units, give each a readable artifact, and add detail views only where inspection is uncertain.

## Bad example

```text
Compress all sections into a tiny collage.
```

## Good example

```text
Provide one readable section view per section, plus a labelled button-detail view where the original is unclear.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

Downstream work can inspect text and spacing without guessing from tiny pixels.

## Limits

Fresh generation may change details; the source blanket no-crop preference is not a universal guarantee.
