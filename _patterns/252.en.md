> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Finish a tested parser change while editing its README.

## Mechanism

Record command, artifact revision and scope; invalidate evidence on an edit affecting that check, not on nervousness alone.

## Bad example

```text
Re-run the identical full build repeatedly on unchanged code.
```

## Good example

```text
Retain the parser test result for its unchanged revision; run documentation checks for the README edit; rerun parser tests only if parser input or code changes.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

Verification effort follows an explicit evidence invalidation rule.

## Limits

External dependencies, nondeterminism or changed fixtures may invalidate results even without source edits.
