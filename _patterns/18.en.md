> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review independent API correctness and accessibility concerns.

## Mechanism

Role separation and common revision make results comparable.

## Bad example

```text
Spawn many agents, have them review everything and vote on bugs.
```

## Good example

```text
Assign one read-only agent API correctness and another accessibility. Give both the same fixed revision and explicit inputs. Merge by trigger and location; verify evidence, keep disagreement, and do not infer truth from vote count.
```

## Why the change matters

Role separation and common revision make results comparable.

## Observable expectation

Every accepted finding has code evidence independent of agreement count.

## Limits

Use one agent when coordination costs exceed independent work; enforce edit ownership.
