## 具体做法

示例展示期望格式及失败例缺失的信息。

## 反例

```text
写好的提交摘要，例如身份认证改动。
```

```text
示例：“增加 token 刷新”→ feat(auth): add token refresh；“拒绝空邮箱”→ fix(validation): reject empty email。反例“改进东西”缺行为和范围。摘要保留实际行为，不照搬示例事实。
```

## 为什么这样改

示例展示期望格式及失败例缺失的信息。
