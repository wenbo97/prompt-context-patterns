> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

将提交信息分类为固定报告格式。

## 机制

示例展示期望格式及失败例缺失的信息。

## Bad example

```text
写好的提交摘要，例如身份认证改动。
```

## Good example

```text
示例：“增加 token 刷新”→ feat(auth): add token refresh；“拒绝空邮箱”→ fix(validation): reject empty email。反例“改进东西”缺行为和范围。摘要保留实际行为，不照搬示例事实。
```

## 差异说明

示例展示期望格式及失败例缺失的信息。

## 可检查的结果

生成摘要有类别、范围与具体行为。

## 适用边界

示例是演示，不证明其中事实适用于新任务。
