> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A workspace operation runs in the wrong directory.

## Mechanism

Inspect the effect’s actual directory value, identify its caller, follow the value through the call chain and verify the originating initialization/decision.

## Bad example

```text
Patch the failing operation to ignore errors without inspecting its input path.
```

## Good example

```text
Observe the empty directory at the operation, trace it to a pre-initialization test value, fix that origin and verify the directory contract.
```

## Why the change matters

The visible failure may occur several boundaries after the defective decision.

## Observable expectation

The explanation records the observed value and each causal call-path hop supporting the identified origin.

## Limits

A call-path hypothesis needs runtime or static evidence; defensive validation alone does not prove the origin or impossibility of recurrence.
