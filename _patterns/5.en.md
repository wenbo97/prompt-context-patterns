> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review an API retry loop for failure behavior.

## Mechanism

The lens supplies review questions without requiring a predetermined verdict.

## Bad example

```text
You are an elite expert. Find a serious bug in this retry loop.
```

## Good example

```text
Review retry.ts as a failure-path reviewer. Check timeout, retry limit and duplicate writes. Report only defects supported by a triggering input and code location; zero findings is valid.
```

## Why the change matters

The lens supplies review questions without requiring a predetermined verdict.

## Observable expectation

Each finding identifies a trigger; an empty report is allowed.

## Limits

A role does not confer expertise or replace domain references and tests.
