> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Assess a third-party skill containing SKILL.md, hooks and helper scripts.

## Mechanism

Install-time behavior may live outside the text the agent loads.

## Bad example

```text
Read SKILL.md; if it looks helpful, declare the package safe.
```

## Good example

```text
Inventory all shipped files. Inspect executable scripts, hooks, dependency manifests and network destinations as well as the entrypoint. Trace credential reads to destinations; record excluded binaries and block installation until critical gaps are resolved.
```

## Why the change matters

Install-time behavior may live outside the text the agent loads.

## Observable expectation

The report accounts for every executable shipped file or explicitly names a gap.

## Limits

Static inspection cannot prove all supply-chain safety; do not execute untrusted scripts during review.
