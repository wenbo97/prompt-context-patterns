> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A memory scan encounters one unreadable decision file while searching for an approval.

## Mechanism

Inspect search diagnostics and preserve complete-empty, incomplete and found outcomes; repair the authorized scan before making absence claims.

## Bad example

```text
One file fails to parse; answer “there is no approval.”
```

## Good example

```text
Report “scan incomplete: decision-17.md unreadable; no approval confirmed,” repair or ask the owning system to resolve that file, then repeat the same scoped lookup.
```

## Why the change matters

A failed scan cannot establish that the requested record does not exist.

## Observable expectation

A test with one corrupt file returns incomplete rather than not-found.

## Limits

This pattern does not authorize widening access or inferring approval from cached text.
