> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

协调一个功能的设计、实现与评审。

## 机制

状态推进要求证据，而非工作者的成功标签。

## Bad example

```text
让 agent 处理开发，随意报告完成内容。
```

## Good example

```text
状态：designed → implemented → reviewed。工作者返回 completed_state、artifact_path、revision、unresolved_items。协调者先核查产物再推进；评审失败则仍处于 implemented。
```

## 差异说明

状态推进要求证据，而非工作者的成功标签。

## 可检查的结果

缺失或失败的评审不能进入 reviewed。

## 适用边界

多个协调者可写入时，须以原子方式更新状态。 将阶段证据绑定到实际输入修订。分别保留完成、不可用、禁用与跳过状态；旧修订或缺失评审维度不能默默满足当前转移门槛。
