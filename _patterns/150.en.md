> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Execute an approved local catalog cleanup in several independent tasks.

## Mechanism

Task completion is not a new permission boundary within an already approved scope.

## Bad example

```text
After each completed task, stop and ask whether to continue.
```

## Good example

```text
Complete each authorized task, record progress and start the next. Pause only for a missing required decision, changed scope or a declared approval boundary. At the end report completed tasks, validation and unresolved work.
```

## Why the change matters

Task completion is not a new permission boundary within an already approved scope.

## Observable expectation

All authorized tasks proceed without repetitive continuation questions.

## Limits

Continue within approved scope; missing required answers and new irreversible effects remain real boundaries. A side question can be answered briefly while retaining the active task and interrupted step. Resume the authorized work after the answer, incorporating explicit corrections; cancellation or a request to pause overrides continuation.
