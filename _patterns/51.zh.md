> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

agent 为发布脚本生成 review.json。

## 机制

执行把模型的格式保证变成可检查结果。

## Bad example

```text
看一下 JSON 就说“schema 已通过”。
```

## Good example

```text
对 review.json 运行给定 JSON Schema 校验器。仅接受退出码 0 与记录的诊断；修复具名违规，最多尝试两次；仍无效则不发布。
```

## 差异说明

执行把模型的格式保证变成可检查结果。

## 可检查的结果

消费的文件就是有校验记录的那个文件。

## 适用边界

schema 通过检查格式，不证明真实性、无障碍或全部行为正确。
