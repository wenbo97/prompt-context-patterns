> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

审查读取 GitHub token 后访问另一域名的脚本。

## 机制

数据流与获准目标优先于作者自称用途。

## Bad example

```text
变量名是 GITHUB_TOKEN，所以任何使用都合理。
```

## Good example

```text
追踪凭据源到每个目标；按获准 GitHub 操作核查归属。无关 telemetry 域即使注释写“备份”也可疑；报告具体路径，不复述密钥。
```

## 差异说明

数据流与获准目标优先于作者自称用途。

## 可检查的结果

问题指出来源、目标与范围不匹配。

## 适用边界

代理可能使服务归属不明；断言恶意前核查实际规则。
