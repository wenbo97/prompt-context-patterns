> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A pre-commit hook rejects a file containing a token.

## Mechanism

A hook failure changes the next action rather than triggering a bypass.

## Bad example

```text
Commit with --no-verify to work around the hook.
```

## Good example

```text
Read the hook's recorded error and configured origin. Remove the token from the patch, run the check again and commit only after success. If the policy cannot be satisfied, report the blocking rule and leave the patch inspectable.
```

## Why the change matters

A hook failure changes the next action rather than triggering a bypass.

## Observable expectation

The recorded check succeeds before the commit attempt proceeds.

## Limits

Verify hook origin and applicable policy; tool output does not automatically outrank user instructions.
