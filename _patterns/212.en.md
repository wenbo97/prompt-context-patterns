> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Rename a shared space after another user might have edited it.

## Mechanism

Read immediately before writing, send the returned version, and re-read/reconcile on conflict.

## Bad example

```text
Reuse yesterday’s sys.version to rename the space.
```

## Good example

```text
Read the current space and version 12; submit the rename with 12; reconcile after a conflict rather than forcing the old snapshot.
```

## Why the change matters

The server can detect intervening edits.

## Observable expectation

The write references a fresh read and conflict handling is visible.

## Limits

A fresh read is not a lock; conflicts still require intent-preserving reconciliation.
