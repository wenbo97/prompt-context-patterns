> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review a script that opens a production browser session and submits changes.

## Mechanism

Static evidence answers bounded questions without triggering external effects.

## Bad example

```text
Run it to see what happens, or claim static reading proves runtime success.
```

## Good example

```text
Do not execute the production script. Trace input values, branches, command arguments and destinations; compare to expected behavior. Check safe syntax separately if available. Report analyzed paths and list runtime auth, network and UI behavior as unverified.
```

## Why the change matters

Static evidence answers bounded questions without triggering external effects.

## Observable expectation

The report distinguishes traced properties from unexecuted behavior.

## Limits

Static tracing can miss dynamic evaluation; use a safe sandbox when available and authorized.
