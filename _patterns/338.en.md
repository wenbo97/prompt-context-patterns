> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Extract numbered quiz questions whose normal format is stable but some entries have missing answers.

## Mechanism

Parse known structures, validate required fields, retain raw text, escalate failed or uncertain records, and revalidate model repairs.

## Bad example

```text
Send every quiz item to a model and accept whatever fields it returns.
```

## Good example

```text
Parse the stable question syntax locally; mark a missing-answer record uncertain; ask the model only about that raw record and validate the returned schema.
```

## Why the change matters

The model handles bounded ambiguity while ordinary extraction stays reproducible.

## Observable expectation

Fixtures identify which records escalate, and all accepted outputs pass the same validation.

## Limits

Do not apply a rigid parser to unrestricted prose; source success percentages are not transferable guarantees.
