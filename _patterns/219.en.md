> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Append one paragraph to an existing project report.

## Mechanism

Inspect tool semantics; use append for additions or read/merge/full payload for a replacement endpoint.

## Bad example

```text
Send only the new paragraph to a tool that replaces the entire document.
```

## Good example

```text
Use the append tool at the end; if only replacement exists, read the report, merge the paragraph and submit the complete content.
```

## Why the change matters

The intended edit is preserved without dropping untouched content.

## Observable expectation

The resulting document still contains the old sections plus the new paragraph.

## Limits

Read-back verification is needed; concurrent edits may require version checks.
