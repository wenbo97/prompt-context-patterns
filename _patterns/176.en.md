> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Upgrade a serializer while promising unchanged public output.

## Mechanism

A differential oracle tests preservation rather than only a candidate's own pass label.

## Bad example

```text
Run only the new suite; if it passes, assert full equivalence.
```

## Good example

```text
Run the same frozen fixtures on old and new serializers. Compare output bytes or the agreed semantic normalization, error type and ordering. Record every delta, including a failure present in both versions; add fixtures for known boundary inputs.
```

## Why the change matters

A differential oracle tests preservation rather than only a candidate's own pass label.

## Observable expectation

No unexplained output or error delta exists in the tested fixture set.

## Limits

Equivalence is limited to the fixtures and comparison definition; it is not proof for all inputs.
