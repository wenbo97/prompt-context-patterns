> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

agent 反复跳过 null 输入回归检查。

## 机制

具名失败线索把熟悉捷径连接到缺失检查。

## Bad example

```text
绝不跳过验证，要有纪律。
```

## Good example

```text
借口“改动很小”→ 运行 null 夹具，大小不验证行为。借口“上次成功”→ 验证当前版本。不能运行时报告缺口，不声称通过。
```

## 差异说明

具名失败线索把熟悉捷径连接到缺失检查。

## 可检查的结果

两种捷径都回到针对版本的验证要求。

## 适用边界

不编造通用成本，也不坚持每个微小修改都需全套测试。
