> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A patch changes lock acquisition order in one function.

## Mechanism

A named escape hatch permits necessary context without unbounded exploration.

## Bad example

```text
Read the entire repository again, or forbid reading outside the diff.
```

## Good example

```text
Read the fixed diff first. Name risk: callers may hold lock B before this function acquires A. Inspect only relevant callers and lock paths; report the additional locations checked and any remaining scope gap.
```

## Why the change matters

A named escape hatch permits necessary context without unbounded exploration.

## Observable expectation

Every outside-diff read corresponds to the stated lock-order risk.

## Limits

A truly cross-cutting change may require broader analysis; report unverified requirements honestly.
