> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A deployment tool times out after accepting a release request.

## Mechanism

Stable action identity prevents ambiguous timeouts from duplicating effects.

## Bad example

```text
Retry deploy repeatedly until it returns success.
```

## Good example

```text
Persist release key r42 before submission. After timeout, query r42 status. Re-submit only through an idempotent API using the same key; advance submitted to healthy only after the recorded health check passes.
```

## Why the change matters

Stable action identity prevents ambiguous timeouts from duplicating effects.

## Observable expectation

Only one release is created for r42, and status reflects observed checks.

## Limits

The API must implement idempotency and concurrency control; prompts cannot supply them.
