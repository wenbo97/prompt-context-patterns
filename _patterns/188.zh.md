> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

更改已发布模式名称，同时保留旧 URL。

## 机制

稳定身份允许编辑名称，不必改每个外部引用。

## Bad example

```text
改标识符，并在所有位置删除旧链接。
```

## Good example

```text
保持模式 ID 100；更新双语展示名，把旧 slug 映射到同一规范 ID。检查无重定向环，旧锚点落到新页或明确兼容入口。
```

## 差异说明

稳定身份允许编辑名称，不必改每个外部引用。

## 可检查的结果

旧、新入口都对应同一有效记录。

## 适用边界

不把撤下 ID 复用于无关方法；合并项映射到明确目标。
