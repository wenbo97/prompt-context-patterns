> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

One review workflow supports Windows and Linux tool adapters.

## Mechanism

Conditions and rendered fixtures make composition inspectable rather than implicit.

## Bad example

```text
Paste every platform's rules into one prompt and resolve contradictions later.
```

## Good example

```text
Keep core-review.md platform-neutral. Include exactly one documented OS adapter based on observed platform. Record fragment revisions and render the assembled prompt in a fixture; reject conflicting tool mappings.
```

## Why the change matters

Conditions and rendered fixtures make composition inspectable rather than implicit.

## Observable expectation

Each fixture has one platform adapter and no contradictory mappings.

## Limits

Check host precedence and conflicting fragments; illustrative file names are not universal platform APIs. An invariant base can be assembled with explicit character, color or other variable slots; inspect the resulting combinations and delimit untrusted slot values.
