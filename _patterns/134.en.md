> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A source-review agent must have no mutation capability.

## Mechanism

A complete boundary closes alternate mutation routes that tool-name bans miss.

## Bad example

```text
Remove the Edit tool but leave unrestricted shell and HTTP writes.
```

## Good example

```text
Expose read/search tools and a read-only checkout. Deny mutation-capable shell commands and network endpoints at the harness boundary. Test an editor write, shell write and remote POST; all must be rejected.
```

## Why the change matters

A complete boundary closes alternate mutation routes that tool-name bans miss.

## Observable expectation

All three write paths fail while source reads continue.

## Limits

Least privilege needs runtime enforcement; a prompt instruction alone is not a security boundary. Resolve supported operation aliases to the canonical effect before permission lookup, dispatch and audit; reject unknown spellings. Generic execution paths that can reach the same effect still need their own enforcement.
