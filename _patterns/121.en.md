> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Reuse a user's test preference and a project's current deployment endpoint.

## Mechanism

Different memory classes carry different verification and update needs.

## Bad example

```text
Store every conversation fact in one permanent memory and trust it forever.
```

## Good example

```text
Store explicit test preference as feedback with its scope; store endpoint as a reference to current config. Before deploying, reread config. Save confirmed useful approaches as well as corrections; silence is not confirmation.
```

## Why the change matters

Different memory classes carry different verification and update needs.

## Observable expectation

Deployment uses the current endpoint, while explicit preferences retain their scope.

## Limits

Do not store secrets or treat silence as a durable preference; current evidence overrides stale notes.
