> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Choose a settings-page layout.

## Mechanism

Vary structure through a shareable selector on one route while retaining host navigation, density and read-only data.

## Bad example

```text
Show three empty screens with different colors.
```

## Good example

```text
Render different navigation and hierarchy variants on the populated settings route using the same data, and share each variant URL.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

Differences can be attributed to structure within the actual surrounding page.

## Limits

Real mutations need stubs; a prototype is not production-quality implementation.
