> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Read a result produced asynchronously under variable load.

## Mechanism

Observe the relevant state or event repeatedly within a time budget; return only when the actual predicate holds, otherwise report timeout.

## Bad example

```text
Sleep 50 ms and assume the result exists.
```

## Good example

```text
Within the agreed timeout, check the live result getter until the target result exists; on expiry report the unmet predicate.
```

## Why the change matters

Elapsed delay alone does not establish the needed state.

## Observable expectation

The read follows an observed readiness condition or a visible timeout result.

## Limits

Timing-behavior tests have a different oracle; choose polling/event strategy and interval for the actual workload.
