> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Build schema, exporter and UI tickets with dependencies.

## Mechanism

Compute readiness from what has landed on the integration branch; dispatch that frontier and merge one result at a time.

## Bad example

```text
Start every ticket concurrently and trust tracker open/closed status for readiness.
```

## Good example

```text
Run independent schema and copy work in worktrees; after schema lands start exporter; serialize merges and recompute readiness from landed commits.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

No task starts on an unmet implementation dependency, and all results converge on one branch.

## Limits

Worktrees postpone shared-file conflicts; credentials and ignored fixtures may be absent.
