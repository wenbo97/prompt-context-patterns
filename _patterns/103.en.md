> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Click a login button on a page that may already be authenticated.

## Mechanism

Observation chooses an action using present state rather than remembered layout.

## Bad example

```text
Click the remembered login coordinates and then type a password.
```

## Good example

```text
Inspect the current screenshot and DOM. If already authenticated, continue to the requested page. Otherwise locate the observed login control, act through its selector, then inspect the resulting state.
```

## Why the change matters

Observation chooses an action using present state rather than remembered layout.

## Observable expectation

The action uses a control that exists in the current page.

## Limits

Re-observe after state-changing actions; inspection does not authorize destructive operations.
