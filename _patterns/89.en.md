> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Rewrite an internal status update for new team members.

## Mechanism

Concrete replacements guide a repeatable edit while protecting technical terms.

## Bad example

```text
Make the status more professional by using sophisticated words.
```

## Good example

```text
Replace 'utilize' with 'use' and 'commence' with 'start'. Turn 'an investigation was performed' into 'we investigated'. Keep API names and approved domain terms unchanged; inspect meaning after each replacement.
```

## Why the change matters

Concrete replacements guide a repeatable edit while protecting technical terms.

## Observable expectation

The rewritten update keeps facts and identifiers unchanged.

## Limits

Do not impose a universal sentence-length target or simplify away necessary distinctions.
