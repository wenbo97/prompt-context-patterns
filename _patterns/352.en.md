> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A JSONL snapshot is 1,000 bytes, of which800 are attachment records; someone asks how much model context remains.

## Mechanism

Label persisted-byte categories and their complete total; obtain active token/headroom from the harness instead of converting byte share into a context claim.

## Bad example

```text
Report “attachments consume80% of the model context, leaving20% room.”
```

## Good example

```text
Report “800/1,000 persisted bytes are attachment records; active token usage and remaining context were not measured,” then use the authorized harness usage surface if available.
```

## Why the change matters

A reproducible byte ratio does not establish a token ratio or runtime loading policy.

## Observable expectation

The report names byte units, snapshot scope, uncategorized records and the separate unknown active-context measure.

## Limits

Do not imply that a valid byte calculation is useless; it answers storage questions within its actual scope.
