> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A team claims its SDK onboarding is faster than peers, although its quickstart paths require different setup and stop at different results.

## Mechanism

Name the target developer, documented start, and first useful result. Record the product and inspected peers with their steps, time, evidence type, journey boundary, design choice, and source. Separate human onboarding from automated execution. Compare durations only when boundaries match; otherwise disclose the mismatch and compare design choices. Label estimates and unknowns, and do not infer that an unmentioned step takes no time. Ask the user to choose the target after the comparison, then carry that answer into later review.

## Bad example

```text
Peer A completes a warm canned demo in two minutes, and Peer B gives no duration. Our fresh install takes five minutes, so claim that Peer A is 2.5 times faster and Peer B has no setup wait.
```

## Good example

```text
For the Python application developer, compare each documented path from a clean install to the first result on the developer’s own callable. Mark Peer A’s scaffolded demo as a different endpoint, Peer B’s duration as unknown, and our fresh-install estimate as an estimate. Compare the closest peer’s relevant choices, cite the source steps, and ask which target fits before changing the plan.
```

## Why the change matters

The comparison becomes useful for a specific developer while preserving what the documents show, what was estimated, and which journeys are actually comparable.

## Observable expectation

The review names the closest relevant peer and explains why, avoids numeric ranking across unlike endpoints, leaves unsupported durations unknown, and records the selected target before implementation changes.

## Limits

A documented workflow or reviewer estimate does not establish observed onboarding time or product efficacy. Numeric comparisons require the same start and result boundary; peer silence is not evidence that a step is absent.
