> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

工具包部分安装，源码读取器存在，但改动文件追踪模块缺失。

## 机制

将可选 import 延迟到对应工具，或在该子系统初始化边界捕获失败。无关工具继续注册，明确不可用能力，隔离诊断失败，修复后允许经核查的重试。

## Bad example

```text
在共享工具入口顶层 import 追踪模块，缺模块便使所有工具无法加载；或捕获后返回空改动列表，假装追踪正常。
```

## Good example

```text
注册独立读取器，在 changed-files 或其隔离初始化边界加载追踪器。缺失时返回 tracker-unavailable 与修复说明，不返回 no-changes；诊断日志失败也捕获，失败 import promise 清除，让修复后可重试。
```

## 差异说明

无关工具被拖垮前，故障已被局部隔离；缺失仍与有效空结果不同。

## 可检查的结果

受控夹具移除追踪器时，读取器仍可启动，changed-files 明确不可用；修复后新的加载可成功。

## 适用边界

只有可选能力可以这样降级；必需安全或检查器依赖按自身策略失败。已注册不证明可用，实际加载器与宿主行为仍需运行测试。
