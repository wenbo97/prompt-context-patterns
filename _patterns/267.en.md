> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Optimize a report-writing skill over several rounds.

## Mechanism

Save the baseline output for each case once; compare every candidate against those files, track judge and case versions, and add a second reference if the first saturates.

## Bad example

```text
Regenerate the baseline every round and compare each win rate as though the opponent stayed fixed.
```

## Good example

```text
Compare v1 and v2 against the same saved baseline; when both saturate, add the v2 reference as a separate column and keep the original column.
```

## Why the change matters

The meaning of a reported win rate stays stable across rounds.

## Observable expectation

The reference hashes and per-case comparison identities can be inspected.

## Limits

Frozen references can become stale and judges can drift. A fixed comparison does not establish broad superiority or detect cross-case mode collapse.
