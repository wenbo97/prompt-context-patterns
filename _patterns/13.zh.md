> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

SQL 评审技能与迁移执行、通用设计存在交叉。

## 机制

边界示例区分相邻意图，并提供交接。

## Bad example

```text
数据库相关任务都用此技能。
```

## Good example

```text
用于检查给定 SQL 迁移的锁定与数据丢失风险。执行迁移走发布流程；没有迁移文件的模式头脑风暴走设计探索。
```

## 差异说明

边界示例区分相邻意图，并提供交接。

## 可检查的结果

评审、执行和头脑风暴进入不同流程。

## 适用边界

供应商或文件类型检测只是线索；用户要求的迁移可能合理地跨供应商。
