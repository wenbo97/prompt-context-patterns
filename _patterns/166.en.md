> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A plan requires exactly net472 and net8.0 across several tasks.

## Mechanism

Exact values preserve constraints that vague summaries silently change.

## Bad example

```text
Tell each worker to use the old and latest runtimes.
```

## Good example

```text
Global constraints from spec: targets=[net472, net8.0]; preserve public signatures. Copy this block into each task brief or reference its fixed artifact. Review outputs against these exact targets, not inferred 'latest'.
```

## Why the change matters

Exact values preserve constraints that vague summaries silently change.

## Observable expectation

Every task consumes the same recorded target list.

## Limits

Do not copy unrelated instructions blindly; identify the authoritative revision and applicable scope.
