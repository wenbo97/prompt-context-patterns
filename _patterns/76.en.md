> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Fetch metadata from two services with independent rate limits.

## Mechanism

Bounded concurrency and backoff avoid amplifying a rejected request stream.

## Bad example

```text
Fire all requests together and instantly retry every failure.
```

## Good example

```text
Use the supplied per-service concurrency limits. On 429, honor Retry-After and retry once; authentication failures do not retry blindly. Collect each service's result independently and report unavailable sources.
```

## Why the change matters

Bounded concurrency and backoff avoid amplifying a rejected request stream.

## Observable expectation

Failed sources do not erase successful unrelated results.

## Limits

Cross-server cancellation behavior is runtime-specific; never assume every 403 cancels all calls.
