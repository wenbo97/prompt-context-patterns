> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A measurement reports contrast34; a model receives that value and describes the clip as contrast34.

## Mechanism

Record what evidence and target values the reviewer saw; use an independent measurement or held-out test for corroboration.

## Bad example

```text
Count the model repeating34 as a second independent validation of the measurement.
```

## Good example

```text
Label its prose “description conditioned on measured contrast34”; obtain a separate calculation from the stable source bytes before claiming corroboration.
```

## Why the change matters

The second output inherited the claimed result, so agreement is not independent evidence.

## Observable expectation

The report distinguishes conditioned prose from an independently obtained check.

## Limits

Independent methods can share errors; disclose inputs and dependencies instead of promising that two checks establish truth.
