> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A patch is cleanly written but exports the wrong file format.

## Mechanism

Orthogonal verdicts keep one dimension from masking another.

## Bad example

```text
Give one overall score and let clean code compensate for wrong behavior.
```

## Good example

```text
Spec axis: requested CSV, actual JSON → fail with output evidence. Standards axis: conventions satisfied → pass with references. Show both independently; do not average them into approval.
```

## Why the change matters

Orthogonal verdicts keep one dimension from masking another.

## Observable expectation

The report preserves spec failure despite standards success.

## Limits

Missing specifications produce unknown on that axis, not an invented standard or automatic fail.
