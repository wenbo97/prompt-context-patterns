> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

为读取 YAML 前置信息的宿主打包 PR 评审技能。

## 机制

具体触发条件区分评审与实现。

## Bad example

```text
name: helper
description: 帮助处理事情
```

## Good example

```text
---
name: pr-review
description: 用户要求评审 PR diff 时，检查具体正确性缺陷。
---
```

## 差异说明

具体触发条件区分评审与实现。

## 可检查的结果

宿主能解析名称与描述，并用评审、实现两个请求检查触发。

## 适用边界

仅使用宿主支持的字段；元数据本身不能强制工具权限。
