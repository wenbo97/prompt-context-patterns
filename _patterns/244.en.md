> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Evaluate a parser optimization.

## Mechanism

Keep command, workload and budget constant; repeat measurements, preserve correctness gates and decide against the observed noise range.

## Bad example

```text
Compare a cold baseline once with a warm optimized run and call a small delta a win.
```

## Good example

```text
Run both revisions on the same workload and cache conditions; compare repeated timings and retain the change only if the effect exceeds normal variation while correctness holds.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

The measured effect is attributable to the tested intervention.

## Limits

Variance estimates depend on sample quality; changes with intentional nonperformance benefits need a separate benefit contract.
