> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review a small patch while the main workspace contains uncommitted work.

## Mechanism

Isolation avoids changing the developer's checkout during review.

## Bad example

```text
Switch the main checkout to the PR branch to inspect its files.
```

## Good example

```text
Record main-worktree status. Create a detached review worktree at the reviewed commit; apply sparse paths if dependencies permit. Inspect the patch there, and compare main status afterward.
```

## Why the change matters

Isolation avoids changing the developer's checkout during review.

## Observable expectation

The main workspace status is identical before and after review.

## Limits

Sparse scope may hide callers; widen it for a named dependency risk and validate worktree paths before cleanup.
