> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Prune a verbose skill without losing evidence citations.

## Mechanism

Ablation tests a sentence's behavioral contribution rather than reader intuition.

## Bad example

```text
Delete every sentence that looks obvious; the agent surely does it already.
```

## Good example

```text
For the citation rule, compare full skill, rule-removed skill and no-skill control on matched cases. Repeat runs and count missing citations. Remove the rule only if the measured behavior stays acceptable for this model and task set.
```

## Why the change matters

Ablation tests a sentence's behavioral contribution rather than reader intuition.

## Observable expectation

The decision records cases, model, repeated outcomes and the removed rule.

## Limits

A no-op conclusion is model- and task-relative; revisit it when the runtime changes.
