> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Test review-versus-test routing.

## Mechanism

Name the correct neighboring skill and require it to outrank the rejected candidate with nonzero match.

## Bad example

```text
Pass write a regression test because the review skill scores zero, even though every skill scores zero.
```

## Good example

```text
Require test-driven-development to outrank code-review on write a regression test; fail the case if neither matches.
```

## Why the change matters

The comparison measures the intended behavioral distinction and prevents a structurally plausible but irrelevant pass.

## Observable expectation

Negative precision cannot pass through an unmatched prompt.

## Limits

This runner is a lexical approximation; actual host routing needs separate behavioral runs.
