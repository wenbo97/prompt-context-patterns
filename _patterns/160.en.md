> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A reviewer receives a full test run tied to the reviewed commit.

## Mechanism

Evidence identity avoids redundant work without forbidding necessary independent checks.

## Bad example

```text
Always rerun the whole suite, or never run any test at all.
```

## Good example

```text
Verify reported command, revision, environment and scope match this diff. Reuse matching results. If a cache-miss path is not covered, run its focused fixture or recommend it; new code invalidates prior evidence for affected paths.
```

## Why the change matters

Evidence identity avoids redundant work without forbidding necessary independent checks.

## Observable expectation

Reused evidence names the same revision; a new doubt has a specific check.

## Limits

Re-run when revision, environment or scope changed; reviewer evidence reuse is not a universal ban on tests.
