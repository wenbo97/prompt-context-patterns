> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Implement a supplied landing-page reference.

## Mechanism

Inspect readable text, relative typography, spacing, colors, components and uncertainties; implement against that extracted contract.

## Bad example

```text
Glance at the image and code a familiar card template.
```

## Good example

```text
Record the headline/CTA, two-column ratio, type hierarchy and unknown hover behavior, then build those observed relationships.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

The implementation can be checked against named observations instead of vague inspiration.

## Limits

A raster cannot establish hidden behavior or exact font identity; label inference and ask or refine uncertain detail.
