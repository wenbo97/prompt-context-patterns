> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A retrieval-agent benchmark stays flat after several prompt reminders to use search.

## Mechanism

Read representative traces and artifacts; separate missing knowledge, wrong grading, unavailable wiring, unreachable content and ordinary variability, then target the evidenced layer.

## Bad example

```text
Add another stronger “always search” instruction after every flat round.
```

## Good example

```text
If traces show search was never registered, repair the harness; if it ran correctly but the grader rejects valid citations, revise and regrade the criterion.
```

## Why the change matters

The tuned prompt is not assumed to be the bottleneck for every failure.

## Observable expectation

Each failure bucket has concrete case evidence and a layer-specific next action.

## Limits

The taxonomy is a diagnostic aid, not proof of root cause. Cases can cross layers; validate the proposed explanation with a controlled probe and preserve unknowns.
