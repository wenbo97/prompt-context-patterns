> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent repeatedly skips the null-input regression check.

## Mechanism

Named failure cues connect a familiar shortcut to its missing check.

## Bad example

```text
Never skip verification; be disciplined.
```

## Good example

```text
Excuse: 'The change is tiny' → run the null fixture; small size does not test behavior. Excuse: 'It worked last time' → verify this revision. If the check cannot run, report the gap rather than a passing claim.
```

## Why the change matters

Named failure cues connect a familiar shortcut to its missing check.

## Observable expectation

Both shortcuts lead to the same revision-specific verification requirement.

## Limits

Do not invent universal costs or insist every trivial edit needs a full suite.
