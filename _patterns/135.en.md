> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Get an independent reviewer after the implementer has defended its design.

## Mechanism

Context selection matches the purpose of the dispatch instead of assuming all agents inherit history.

## Bad example

```text
Fork the entire implementation discussion into the independent reviewer.
```

## Good example

```text
Use a fresh reviewer with the revision, requirements and artifact paths; omit the author's preferred verdict. For a worker continuing the same task, use inherited context only if the host documents what is inherited.
```

## Why the change matters

Context selection matches the purpose of the dispatch instead of assuming all agents inherit history.

## Observable expectation

The reviewer receives facts and scope without the implementer's verdict cues.

## Limits

Inheritance and cache behavior depend on the host; fresh context does not guarantee unbiased judgment.
