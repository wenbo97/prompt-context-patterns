> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review whitespace-email handling in a validator without changing state.

## Mechanism

Named prohibited effects distinguish inspection from authorized mutation.

## Bad example

```text
Review validator.py and fix any issues while you are there.
```

## Good example

```text
Read validator.py and its callers; return defects with locations and triggering inputs. Do not modify files, stage changes, create tickets or post comments. If a fix is needed, describe it as a proposed patch.
```

## Why the change matters

Named prohibited effects distinguish inspection from authorized mutation.

## Observable expectation

The review leaves filesystem, git and remote state unchanged.

## Limits

A read-only prompt is not tool enforcement; inspect shell and network routes too.
