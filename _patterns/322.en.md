> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A brand helper reads docs/brand-guidelines.md and writes project design tokens.

## Mechanism

Name both roots; invoke the installed helper by its resolved path without changing the project cwd, and resolve its inputs and outputs according to the helper contract.

## Bad example

```text
Change into the installed skill directory, then run the helper and accidentally write project files into the package.
```

## Good example

```text
Run the absolute helper path from the project root; verify docs/brand-guidelines.md and generated token files resolve inside that project.
```

## Why the change matters

The location of executable code is separated from the location of task data.

## Observable expectation

The invoked path, cwd and resolved artifact paths can be inspected.

## Limits

Some helpers use explicit path arguments or another documented base. Check the actual contract; root separation alone does not enforce path confinement or permission. Keep installed helper roots separate from project-owned outputs; force flags do not authorize replacement of arbitrary project files.
