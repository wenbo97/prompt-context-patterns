> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

一个 JSONL 快照共1,000字节，其中800字节为附件记录；用户问剩余模型上下文。

## 机制

标明落盘字节分类和完整总量，活跃 token 与剩余空间另由运行时获取，不用字节占比替代。

## Bad example

```text
报告“附件占模型上下文80%，还剩20%”。
```

## Good example

```text
报告“落盘1,000字节中附件记录800字节；未测活跃 token 和剩余空间”，可用时再查询授权运行时用量。
```

## 差异说明

可复算字节比不证明 token 比或运行时加载策略。

## 可检查的结果

报告说明字节单位、快照范围、未分类记录和独立未知的活跃上下文指标。

## 适用边界

正确字节计算能回答其范围内的存储问题，不能因边界限制就否定它。
