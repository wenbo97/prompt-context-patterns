> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A build keeps failing after attempted dependency repairs.

## Mechanism

An explicit budget prevents unlimited retry and retains diagnostic history.

## Bad example

```text
Keep changing dependencies until the build eventually passes.
```

## Good example

```text
Allow three repair attempts. Each records error signature, hypothesis, change and covering check. If the same signature persists or the cap is reached, stop, preserve the diff and report remaining errors as blocked.
```

## Why the change matters

An explicit budget prevents unlimited retry and retains diagnostic history.

## Observable expectation

Attempts never exceed three, and exhaustion is not marked complete.

## Limits

Choose limits for the task; a universal attempt count does not guarantee convergence.
