> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent can search source using either precise search or a general chat endpoint.

## Mechanism

The table binds a capability to an interface and evidence type.

## Bad example

```text
Use any tool that can answer where validateEmail is defined.
```

## Good example

```text
Source lookup → code_search with symbol=validateEmail. Read result → source_read with returned path. General chat is not source evidence. If these tools are absent, use the documented local search adapter and label its result.
```

## Why the change matters

The table binds a capability to an interface and evidence type.

## Observable expectation

A location claim comes from retrieved source rather than a conversational guess.

## Limits

The preferred tool depends on the host; never call an undocumented identifier.
