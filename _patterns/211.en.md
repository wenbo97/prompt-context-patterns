## Use case

A contact lookup returns HTTP 403.

## Mechanism

Inspect service error details; repair credentials/permissions for auth failures, arguments for validation, backoff for throttling, and accept documented empty results.

## Bad example

```text
Retry the identical 403 request ten times.
```

## Good example

```text
Read the access error; stop retries; identify missing permission and resume only after credentials are repaired.
```

## Why the change matters

Retries do not repair deterministic configuration errors.

## Observable expectation

The recovery action matches the recorded error class.

## Limits

Status codes alone may be ambiguous; use service error details and bounded retries.
