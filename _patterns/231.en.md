> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Reuse documentation first read for an API signature while researching its error semantics.

## Mechanism

Record both source version and transformation question; reuse a derived reading only when it covers the new task, otherwise refetch or rederive from raw content.

## Bad example

```text
Origin says 304, so the old signature-only summary answers the error question.
```

## Good example

```text
Check the original extraction prompt; if it only requested signatures, fetch the missing error section or rederive from the unchanged raw page.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

Unchanged source content is not mistaken for complete coverage of the new question.

## Limits

The observed hook is URL-only and leaves relevance judgment to the agent; it does not enforce this invariant automatically.
