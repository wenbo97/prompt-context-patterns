> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Configure a host with native skill discovery.

## Mechanism

Detect the actual host discovery capability and choose one active routing authority; keep reusable skills available on demand.

## Bad example

```text
Preload two full lifecycle routers and let both dispatch the task.
```

## Good example

```text
Use the native router with the installed skill descriptions; load the meta-router only where the host lacks that capability.
```

## Why the change matters

The procedure preserves the stated identity or evidence boundary instead of allowing a plausible shortcut to stand in for it.

## Observable expectation

The same task does not receive competing dispatch protocols.

## Limits

Verify effective runtime discovery; installation or metadata alone is not proof that native routing works.
