> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Add dead-link checking to a documentation repository.

## Mechanism

Inspect local helpers, available registries and maintained source implementations; compare fit and choose adopt, extend, compose or build.

## Bad example

```text
Write a new link checker without looking at existing maintenance scripts.
```

## Good example

```text
Find the existing checker, verify anchor coverage, extend its missing locale handling, and state which search channels were available.
```

## Why the change matters

The task reuses the current architecture and exposes the reason custom work is still needed.

## Observable expectation

The decision lists candidate sources, compatibility and the selected path.

## Limits

An unavailable channel is not evidence of no solution; packages must be reviewed before execution.
