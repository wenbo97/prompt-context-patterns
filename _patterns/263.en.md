> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A service launches several jobs with one reviewed agent configuration.

## Mechanism

Create or update the definition in setup, persist its identity and version, and create runs that explicitly reference the approved version; treat live-run overrides separately.

## Bad example

```text
Create a fresh untracked definition for every job and refer to latest without recording which configuration ran.
```

## Good example

```text
Persist definition v3 once; launch each job with a distinct run ID pinned to v3 and record any run-specific override.
```

## Why the change matters

Definition changes and execution history remain distinguishable.

## Observable expectation

Definition/version/run relationships and configuration changes can be checked.

## Limits

The host must actually support the declared versioning contract. A pinned definition does not freeze external tools, credentials, data or dependencies.
