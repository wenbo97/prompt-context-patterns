> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

评审技能演示 PostgreSQL 参数绑定，而宿主会展开技能正文中的位置参数标记。

## 机制

用代表性参数检查实际渲染的调用。通过已记录的不展开引用或转义机制保护冲突字面值；若都不可用，改用文字解释绑定，不破坏驱动语法。

## Bad example

```text
在会插值的技能正文写 SELECT * FROM users WHERE id = $1，假定 /review alice 后示例仍原样存在。
```

## Good example

```text
把 PostgreSQL 示例放在已核查的不展开引用，或用宿主已记录的转义。渲染 /review alice 和无参数调用，核对查询占位符及参数数组。无保护机制时用文字说明 PostgreSQL 参数绑定。
```

## 差异说明

同一字符可能被两个解释器赋予含义；合法 SQL 示例可能在模型看到前就被转换。

## 可检查的结果

两种调用都保留预期参数绑定语义，或技能明确使用文字回退。

## 适用边界

预处理行为只是来源中的观察警告，不是通用事实。保持实际驱动语法；问号不是 PostgreSQL 的通用替代。未测试展开边界前，不能假定引用文件不被处理。
