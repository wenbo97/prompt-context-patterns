> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

用已安装 SaaS 连接器读取项目 issue。

## 具体做法

发现将当前能力、认证与实际 schema 绑定。

## 反例

```text
调用想象的 fetchIssue 工具，并假定连接活动。
```

## 改进写法

```text
搜索连接器可用的 issue 读取操作，阅读返回 schema 并核查账号连接。以请求的项目、issue ID 执行已记录读取；不可用时报告缺口，不编造 slug。
```

## 为什么这样改

发现将当前能力、认证与实际 schema 绑定。

## 如何验证

调用使用已发现操作，返回真实 issue 或明确失败。

## 适用边界

操作名与连接状态依连接器而异；不推断已有发送消息许可。
