> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Generate checkout, receipt and order-detail mockups.

## Mechanism

Write a common design bible before generating the set; distinguish invariant palette/type/navigation from allowed layout and emphasis changes.

## Bad example

```text
Choose a fresh palette and navigation for each screen.
```

## Good example

```text
Lock palette, type scale and bottom navigation; vary the checkout form, receipt summary and detail composition according to purpose.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

The set varies without becoming unrelated products.

## Limits

An internal bible is a plan; compare actual outputs before claiming consistency.
