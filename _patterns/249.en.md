> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review a cache that intentionally returns stale data under a stated tolerance.

## Mechanism

Check contract misread first, then actionable defect, accepted tradeoff and context-caused noise; fix the contract before repeating review when it caused the error.

## Bad example

```text
Fix every reviewer complaint or dismiss all disagreement as noise.
```

## Good example

```text
Re-read each finding: clarify the missing tolerance first; fix a real unbounded-staleness path; record an accepted latency tradeoff separately.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

The artifact changes only for validated actionable findings, with contract failures distinguished.

## Limits

Classification is an editorial judgment; a reviewer disagreement alone proves neither author nor reviewer correct.
