> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

实现者已辩护设计后，需要独立评审。

## 机制

上下文选择依派发目的，不假定所有 agent 继承历史。

## Bad example

```text
把完整实现讨论 fork 给独立评审者。
```

## Good example

```text
为新评审者提供版本、要求、产物路径，不附作者偏好结论。继续同一任务的工作者仅在宿主明确继承内容时使用继承上下文。
```

## 差异说明

上下文选择依派发目的，不假定所有 agent 继承历史。

## 可检查的结果

评审者获得事实和范围，没有实现者结论暗示。

## 适用边界

继承与缓存行为依宿主而定；新上下文不保证判断无偏。
