> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Route a document request to read, create or format-preserving edit.

## Mechanism

Specific predicates and the unmatched branch limit silent routing assumptions.

## Bad example

```text
Handle the document with whichever workflow seems best.
```

## Good example

```text
Existing file + summarize request: read. No file + new draft request: create. Existing file + requested changes: edit while preserving styles. Conflicting signals: state candidates and ask before modifying.
```

## Why the change matters

Specific predicates and the unmatched branch limit silent routing assumptions.

## Observable expectation

Each request selects one workflow or explicitly remains ambiguous.

## Limits

Examples such as chart and incident routing need their own domain-approved criteria.
