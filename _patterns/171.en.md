> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Use one review skill on hosts with different source-read tool names.

## Mechanism

A binding layer preserves task semantics while changing concrete interfaces.

## Bad example

```text
Hardcode mcp_vendor_read everywhere and assume every host exposes it.
```

## Good example

```text
Core instruction: retrieve source by returned path. Adapter A binds that to source_read; Adapter B binds it to documented local-file read. Select one adapter from known host capabilities; unknown host returns a capability gap.
```

## Why the change matters

A binding layer preserves task semantics while changing concrete interfaces.

## Observable expectation

Each host uses an available documented tool for the same read operation.

## Limits

Capability verbs still need real adapters and schemas; abstraction does not create unavailable tools.
