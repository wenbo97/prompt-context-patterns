> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Redact the same private account in a report and its supporting transcript.

## Mechanism

Map the value to one stable placeholder in every copy, preserve source markers and log only placeholder/category/count.

## Bad example

```text
Replace one occurrence with ACCOUNT-1 and another with REDACTED, while storing the secret replacement map in the bundle.
```

## Good example

```text
Use ORG-1 consistently in report and transcript; keep original line markers; write only ORG-1/category/count to the log.
```

## Why the change matters

Stable anonymous identity preserves relationships without exposing the original value.

## Observable expectation

Citations and cross-file relationships remain checkable and the export contains no plaintext mapping.

## Limits

If privacy removes evidence support, report the limitation instead of retaining secrets. When redaction collapses distinct keys to one label, retain each observation with a stable opaque identity or collision suffix. Redact structured values before encoding or truncation.
