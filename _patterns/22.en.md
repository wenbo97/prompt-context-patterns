> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Two reviewers report a null dereference and a timeout in the same function.

## Mechanism

Semantic keys distinguish duplicate reports from nearby independent defects.

## Bad example

```text
Merge all findings in the same file into one issue.
```

## Good example

```text
Use key=(symbol, trigger, failure). Merge two cache-miss null dereferences, retaining both evidence links. Keep the timeout as separate: it has a different trigger and failure. Record disagreements instead of averaging severity.
```

## Why the change matters

Semantic keys distinguish duplicate reports from nearby independent defects.

## Observable expectation

The final list has one null finding and one timeout finding.

## Limits

Line proximity and model agreement are hints, not proof of identical cause.
