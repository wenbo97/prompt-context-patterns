> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

为新团队成员改写内部状态更新。

## 机制

具体替换引导可重复修改，同时保护技术术语。

## Bad example

```text
使用高级词汇，让状态更新更专业。
```

## Good example

```text
utilize 改 use，commence 改 start；“执行了一次调查”改“我们调查了”。保留 API 名与已认可的领域术语，每次替换后检查含义。
```

## 差异说明

具体替换引导可重复修改，同时保护技术术语。

## 可检查的结果

改写后事实与标识符不变。

## 适用边界

不强加通用句长目标，也不把必要区别简化掉。
