> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Use an existing threat-model skill before a security review.

## Mechanism

An artifact contract turns a vague delegation into a consumable handoff.

## Bad example

```text
Do some threat modeling and maybe use another skill.
```

## Good example

```text
Invoke threat-model with the repository path. Expect threats.json containing id, boundary and threat. Validate the artifact, then pass its path to security-review; if unavailable, report the missing capability.
```

## Why the change matters

An artifact contract turns a vague delegation into a consumable handoff.

## Observable expectation

The second skill receives validated threat records or a named gap.

## Limits

Do not invent invocation APIs or silently install dependencies.
