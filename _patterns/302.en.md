> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Install an import-boundary rule.

## Mechanism

Observe pass on allowed input, fail on a temporary forbidden input, and pass after removal.

## Bad example

```text
Check that the configuration file exists.
```

## Good example

```text
Run the clean package, inject a forbidden deep import and observe the named error, remove it and observe success.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

The installed rule is demonstrably wired to the actual command.

## Limits

One counterexample does not establish complete bypass resistance.
