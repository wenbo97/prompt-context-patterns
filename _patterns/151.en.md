> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A deployment requires a reviewed release candidate before submission.

## Mechanism

The label makes the precondition easy to locate; the SHA check defines satisfaction.

## Bad example

```text
Important: make sure review happened before deployment.
```

## Good example

```text
<HARD-GATE>Submit only after candidate SHA matches the recorded approved SHA. If approval is absent or stale, prepare the candidate report and wait at this gate.</HARD-GATE>
```

## Why the change matters

The label makes the precondition easy to locate; the SHA check defines satisfaction.

## Observable expectation

A mismatched candidate cannot be submitted under the old approval.

## Limits

A visible tag is a prompt convention, not an enforced tool boundary.
