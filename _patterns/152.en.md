> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Route an issue to bug reproduction, feature planning or clarification.

## Mechanism

Labeled transitions expose the re-entry and exit behavior.

## Bad example

```text
Triage the issue appropriately; ask if unclear.
```

## Good example

```text
digraph triage { start -> reproduce [label="observed failure"]; start -> plan [label="new behavior request"]; start -> clarify [label="ambiguous"]; clarify -> start [label="answer received"]; }
Apply one matching edge; unresolved ambiguity stays clarify.
```

## Why the change matters

Labeled transitions expose the re-entry and exit behavior.

## Observable expectation

Each fixture reaches the named state, including clarification re-entry.

## Limits

Keep graphs small and define ambiguous matches; DOT syntax is not proof of correct execution.
