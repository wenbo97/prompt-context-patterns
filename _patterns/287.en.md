> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Implement an export request whose audience, fields and delivery destination are unspecified.

## Mechanism

Inspect what is known, list the consequential unknowns, present plausible interpretations and resolve only the decisions that change the implementation.

## Bad example

```text
Assume all records, every field and a public file destination without telling the user.
```

## Good example

```text
State the unresolved export scope and sensitive-field choice; offer concrete supported interpretations; use the selected scope in implementation.
```

## Why the change matters

The decision-maker sees choices that would otherwise be silently invented.

## Observable expectation

The resulting requirement record names chosen scope, fields and destination, with assumptions distinguished from facts.

## Limits

Explore discoverable facts first; trivial settled details do not require an interview.
