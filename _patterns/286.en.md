> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Verify serialization of a search filter.

## Mechanism

Use a hand-checked literal expected output and consider wrong quoting, missing field or wrong branch mutations.

## Bad example

```text
Compute both expected and actual with the same query builder.
```

## Good example

```text
Compare the builder result to a manually verified literal; confirm that omitting the filter or changing its quoting would fail the assertion.
```

## Why the change matters

A shared implementation can repeat the same defect on both sides of an equality.

## Observable expectation

At least the relevant plausible defects change the asserted outcome.

## Limits

Mutation sensitivity is scoped to identified risks, not proof that every possible bug is covered.
