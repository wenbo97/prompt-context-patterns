> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Open a compose panel when selectThread(null) also resets composeOpen to false.

## Mechanism

Inspect state effects of each action, order reset before open or use one coherent transition, then verify the final visible state.

## Bad example

```text
Run setComposeOpen(true), then selectThread(null); report success because the first setter ran.
```

## Good example

```text
Run selectThread(null), then setComposeOpen(true); check the resulting state and that the compose panel remains visible.
```

## Why the change matters

A locally correct call can be overwritten by the next call in the same interaction.

## Observable expectation

The final state is composeOpen=true after the whole sequence, with a regression for the order.

## Limits

Use the application’s actual transition contract; changing order can alter other effects and needs their intended assertions.
