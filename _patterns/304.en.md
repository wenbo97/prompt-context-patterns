> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Queue a JSON-output fix for next week.

## Mechanism

State current/desired behavior, independently testable acceptance criteria, interface names and exclusions.

## Bad example

```text
Edit handler.ts line 80 and add a switch.
```

## Good example

```text
Under --json emit valid JSON for success and errors, preserve exit codes; modify the output interface; exclude other commands.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

A renamed file does not invalidate the task contract.

## Limits

Exact paths remain useful for immediate observations; durable handoffs still need version context.
