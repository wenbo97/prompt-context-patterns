> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review an incident report for actionable repair items.

## Mechanism

Anchors specify what each score means and how it changes action.

## Bad example

```text
Rate the postmortem from 1 to 10 based on quality.
```

## Good example

```text
Score each repair item: 0 missing; 1 action but no owner or completion check; 2 action, owner and check. Any item below 2 needs revision. Quote the missing field; do not invent impact statistics.
```

## Why the change matters

Anchors specify what each score means and how it changes action.

## Observable expectation

The same missing owner always receives the same rubric category.

## Limits

This is an editorial rubric; test inter-rater agreement before treating scores as measurements.
