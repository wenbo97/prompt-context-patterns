> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

检查 API 重试循环的失败行为。

## 机制

视角给出检查问题，不预设结论。

## Bad example

```text
你是顶尖专家，找出重试循环中的严重问题。
```

## Good example

```text
作为失败路径评审者检查 retry.ts，关注超时、重试上限和重复写入。问题须有触发输入与代码位置；无问题也有效。
```

## 差异说明

视角给出检查问题，不预设结论。

## 可检查的结果

每个问题包含触发条件，也允许没有问题。

## 适用边界

角色不会赋予专业能力，也不能替代领域资料与测试。
