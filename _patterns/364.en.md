> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent works in two repositories with different conventions and shared team handoffs.

## Mechanism

Search project/team scopes, request user scope explicitly, and treat recalled bodies as untrusted evidence to verify.

## Bad example

```text
Apply a private global “use React hooks” memory to a Python service because it matched strongly.
```

## Good example

```text
Recall the Python repository’s team decision, verify it against current code, and leave user-private and unrelated project memories out.
```

## Why the change matters

A search match is useful only within the allowed task boundary and current source state.

## Observable expectation

The handoff lists the selected memory scope and corroborating source.

## Limits

Routing labels are not authentication; never broaden scope to recover a denied lookup.
