> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Three skills repeat an instruction to preserve raw source evidence, while a fourth contains only one vendor-specific command.

## Mechanism

Cross-read candidate skills and current rules; require repeated evidence, behavior change and violation risk; merge semantic duplicates and keep narrow recipes local.

## Bad example

```text
Turn every heading into a global rule and duplicate existing policy with new wording.
```

## Good example

```text
Promote “retain source and observation time before memory reuse” with the two source sections and stale-recall risk; keep the vendor CLI command inside its own skill.
```

## Why the change matters

The filter reduces abstraction that has no transferable action or new value.

## Observable expectation

The proposal lists source sections, risk, matching existing rule and append/revise/local verdict.

## Limits

Recurrence alone does not prove a rule is correct; retain exceptions and the project’s normal policy-review authority.
