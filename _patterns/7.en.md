> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

The user requests a user-data export but has not specified fields.

## Mechanism

Inspection resolves discoverable facts; live answers resolve intent.

## Bad example

```text
Export all user fields as JSON to users.json.
```

## Good example

```text
Read the existing export interface. Fields and destination are still unspecified: ask which fields to include, then wait. Reuse answers already given; continue independent interface inspection.
```

## Why the change matters

Inspection resolves discoverable facts; live answers resolve intent.

## Observable expectation

No export is executed using invented fields or destinations.

## Limits

Do not force a fixed number of questions when the task is already specified.
