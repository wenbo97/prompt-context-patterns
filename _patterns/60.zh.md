> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

评审 agent 可读源码，不能发布或修改生产。

## 机制

分类把意图连接到可强制的能力决定。

## Bad example

```text
除非 agent 感觉不安全，否则允许所有操作。
```

## Good example

```text
策略：读源码允许；发布评审需范围明确的授权；生产修改禁止。在工具层执行，覆盖 shell、网络路径。拒绝时报告策略原因，不换工具重试。
```

## 差异说明

分类把意图连接到可强制的能力决定。

## 可检查的结果

替代执行路径仍不能做被禁止的生产写入。

## 适用边界

按部署制定策略；任意 hook 文本不能变成用户授权。
