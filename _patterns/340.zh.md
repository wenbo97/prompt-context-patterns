> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

停止采集任务后，导出产物 ID 会晚于采集进程结束到达。

## 具体做法

先停止生产者，再在有界期限内等当前运行的终态导出或明确失败，记录结果后停止监听器。

## 反例

```text
先杀监听器，再停止采集，未收到最终产物 ID 就报告完成。
```

## 改进写法

```text
停止采集而保留监听，只接纳匹配当前运行的 exported 事件，记下产物 ID 后清理监听。
```

## 为什么这样改

生产者停止可能启动最终处理，过早移除观察者会丢失区分已停止与已完成的证据。

## 如何验证

报告有当前运行终态，或明确的未决超时；随后才清理观察者。

## 适用边界

核对运行身份与旧日志。回执不证产物质量或持久可得；断连及模糊超时应核对状态，不能盲目重试。
