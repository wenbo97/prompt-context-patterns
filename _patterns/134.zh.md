> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

源码评审 agent 必须没有修改能力。

## 具体做法

完整边界堵住仅禁工具名会遗漏的替代修改路径。

## 反例

```text
移除 Edit 工具，却保留无限制 shell 与 HTTP 写入。
```

## 改进写法

```text
暴露只读搜索工具与只读检出。在宿主边界禁止可修改的 shell 命令、网络端点；测试编辑写入、shell 写入、远端 POST，均须拒绝。
```

## 为什么这样改

完整边界堵住仅禁工具名会遗漏的替代修改路径。

## 如何验证

三条写入路径都失败，源码读取仍有效。

## 适用边界

最小权限需要运行时执行；提示词指令本身不是安全边界。 在权限查询、派发和审计前，将支持的操作别名解析为规范效果，并拒绝未知拼写。能够到达同一效果的通用执行路径仍需单独执行约束。
