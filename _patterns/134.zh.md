> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

源码评审 agent 必须没有修改能力。

## 机制

完整边界堵住仅禁工具名会遗漏的替代修改路径。

## Bad example

```text
移除 Edit 工具，却保留无限制 shell 与 HTTP 写入。
```

## Good example

```text
暴露只读搜索工具与只读检出。在宿主边界禁止可修改的 shell 命令、网络端点；测试编辑写入、shell 写入、远端 POST，均须拒绝。
```

## 差异说明

完整边界堵住仅禁工具名会遗漏的替代修改路径。

## 可检查的结果

三条写入路径都失败，源码读取仍有效。

## 适用边界

最小权限需要运行时执行；提示词指令本身不是安全边界。
