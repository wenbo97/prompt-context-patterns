> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Add monitoring for an import failure.

## Mechanism

Use an authorized isolated test to induce an error/event, trace its identifier and verify structured fields, labels, propagation and alert delivery.

## Bad example

```text
Declare monitoring ready because the logging code exists.
```

## Good example

```text
Induce one test import failure, find its run ID in the aggregator, follow its trace and verify the test alert points to the right runbook.
```

## Why the change matters

The procedure preserves the stated identity or evidence boundary instead of allowing a plausible shortcut to stand in for it.

## Observable expectation

Instrumentation availability is distinguished from a working evidence path.

## Limits

Induced failures and notifications must stay within authorized test scope; this audit did not fire any alerts.
