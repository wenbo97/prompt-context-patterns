> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

把 issue 分到错误复现、功能规划或澄清。

## 机制

带条件转移使重入与退出行为可见。

## Bad example

```text
适当分诊 issue，不明确就问。
```

## Good example

```text
digraph triage { start -> reproduce [label="observed failure"]; start -> plan [label="new behavior request"]; start -> clarify [label="ambiguous"]; clarify -> start [label="answer received"]; }
按匹配边执行；歧义未解决则留在 clarify。
```

## 差异说明

带条件转移使重入与退出行为可见。

## 可检查的结果

每个夹具进入规定状态，包括澄清后的重入。

## 适用边界

图保持简短，明确歧义匹配；DOT 语法不证明执行正确。
