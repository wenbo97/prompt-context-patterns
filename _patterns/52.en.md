> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Grade answers for whether they preserve a supplied incident's facts.

## Mechanism

A fixed rubric makes the evaluator's criteria visible and contestable.

## Bad example

```text
Judge which answer feels higher quality and give an overall score.
```

## Good example

```text
For each answer, check: incident time matches input, impact is supported, unknown cause remains unknown. Return pass/fail/unknown per item with the supporting sentence. Verify objective fields with code before accepting the model judgment.
```

## Why the change matters

A fixed rubric makes the evaluator's criteria visible and contestable.

## Observable expectation

Unsupported new causes fail even if prose reads fluently.

## Limits

Model grading can be biased; calibrate against human labels and permit ties or unknown.
