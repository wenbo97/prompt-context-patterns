> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Verify that a generated scene places a prop in contact with the intended surface.

## Mechanism

Read scoped object transforms/geometry/contact state and inspect the corresponding rendered frame with the same scene/version identity.

## Bad example

```text
Declare contact from a plausible screenshot while the prop’s geometry actually floats above the surface.
```

## Good example

```text
Record the object and surface transforms/contact check, then inspect the rendered frame to confirm the intended visible placement.
```

## Why the change matters

Pixels show appearance; structured state exposes hidden coordinates and object identity.

## Observable expectation

The report binds both observations to the same scene checkpoint and names unresolved placement differences.

## Limits

Do not infer physical correctness from arbitrary numeric defaults; neither a screenshot nor a state receipt alone proves the whole motion or saved artifact.
