> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A cloud-deploy skill supports AWS and Azure references.

## Mechanism

Conditional pointers connect relevant detail to the selected task without loading every branch.

## Bad example

```text
Load both providers' full guides for every deployment request.
```

## Good example

```text
Entrypoint contains common validation and provider selection. For AWS, read references/aws.md; for Azure, read references/azure.md. Keep authorization boundaries inline. If provider is unknown, resolve it before loading a branch.
```

## Why the change matters

Conditional pointers connect relevant detail to the selected task without loading every branch.

## Observable expectation

An AWS run loads its guide and records why Azure was not needed.

## Limits

Loading still consumes context and is host-dependent; critical shared rules must remain reachable.
