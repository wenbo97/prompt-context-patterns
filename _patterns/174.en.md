> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Audit a framework upgrade with many documented breaking changes.

## Mechanism

Reachability distinguishes applicable risk from general migration documentation.

## Bad example

```text
List every global breaking change as a confirmed defect in this project.
```

## Good example

```text
Inventory imported APIs and traced callers. Intersect that set with version-specific changes. For each reachable change show the local path and required check; list unobserved runtime-loaded APIs as a coverage gap.
```

## Why the change matters

Reachability distinguishes applicable risk from general migration documentation.

## Observable expectation

Every confirmed local concern has a code path or explicitly provisional dynamic assumption.

## Limits

Static reachability can miss reflection and plugins; do not claim complete absence from imports alone.
