> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A background evidence extractor exits0 after reporting that its required input could not be read.

## Mechanism

Define a completion record emitted only after required reads/writes succeed; validate the current run’s exact record separately from exit status and retain inputs on incomplete work.

## Bad example

```text
Treat exit0 as success and archive the only pending input despite the blocked read.
```

## Good example

```text
Require exit0 plus exactly one final analysis_complete record from this run; when the record is absent, keep the input pending and report incomplete.
```

## Why the change matters

Transport/process completion does not establish that the intended task completed.

## Observable expectation

A blocked-read fixture with exit0 remains incomplete; a valid no-findings completion can still be acknowledged.

## Limits

A model-issued marker is a self-report, not proof of every write. Independently check required artifacts and acknowledge only the exact input snapshot actually processed.
