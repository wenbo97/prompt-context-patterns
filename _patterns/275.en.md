> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Compare two support-agent prompts before rollout.

## Mechanism

Call the actual test-mode entry point; mock only unsafe external dependencies, preserve context/retry/tool wiring, and record the served configuration and a complete pilot result.

## Bad example

```text
Send the copied system prompt directly to a model and report that the support application improved.
```

## Good example

```text
Call the support handler with a disposable account; retain its retrieval and tools, stub outgoing messages, and inspect one full trace before the larger run.
```

## Why the change matters

A reconstructed request can bypass the behavior whose quality the task asks about.

## Observable expectation

The exercised entry point, substituted dependencies and actual trace are inspectable.

## Limits

Test-mode parity must be checked; a reported model ID may not expose every provider substitution. Live side effects require the applicable authorization.
