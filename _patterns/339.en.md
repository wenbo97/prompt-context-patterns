> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

README, an architecture map and a weekly status report repeat the same migration state.

## Mechanism

Choose the canonical status owner; keep architectural rules in their own owner and replace repeated facts elsewhere with links.

## Bad example

```text
Update README to completed while the architecture map still says blocked and the status report has a third answer.
```

## Good example

```text
Write current migration status in the status record, architecture constraints in the design record, and link the README to those owners.
```

## Why the change matters

Independent copies no longer compete as current authority for the same fact.

## Observable expectation

A reader can follow each overview claim to a named canonical owner and current state.

## Limits

Different audiences may need summaries; label them as derived and maintain freshness rather than forbidding all repetition.
