> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A discovered upload tool returns schemaRef rather than inline fields.

## Mechanism

Fetch the full schema, inspect required fields/types, then construct and validate arguments.

## Bad example

```text
Treat schemaRef as a complete schema and guess file/content fields.
```

## Good example

```text
Resolve schemaRef; inspect required file object and format fields; submit only supported fields.
```

## Why the change matters

A reference names information; it does not contain that information.

## Observable expectation

The execution payload matches a full schema fetched in this workflow.

## Limits

Do not expand unrelated tool schemas; refresh if the service changes the contract.
