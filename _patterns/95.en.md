> These examples and illustrative results are independently authored teaching materials, not measured model results.

## Use case

A dependency build failure has been diagnosed, and you want to reuse its evidence next time. Teaching records show project tool-a with dependency 2.1 reporting 'adapter entry missing'; adding the configuration's entry field under the same input leads to build exit 0. This observation does not establish the same cause for every version.

## Mechanism

In an authorized project record, save the signature, version, confirmed cause, fix and check result with artifact locations. Include applicability and disconfirming evidence. On recurrence compare current version, signature and configuration before using the note as a candidate diagnosis. Revise or supersede contradictions rather than promoting one success into a global rule.

## Bad example

```text
Use the single success above to permanently require an entry field in every build. Apply it immediately to any future build error.
```
{: .example--bad}

## Good example

```text
Save this lesson in the authorized tool-a project record: version 2.1, the adapter entry missing log location, configuration evidence for the absent entry, the change and exit-0 check. Apply only to matching version and adapter configuration; other versions or signatures require inspection. Compare current evidence on reuse and revise contradictions. This teaching success does not explain every build failure.
```
{: .example--good}

## Why the change matters

A fix alone loses the conditions that made it relevant. Signature, version, evidence and disconfirming conditions let later readers decide whether reuse is justified rather than turning an incident into an unconditional instruction.

## Observable expectation

Compare two later fixtures: version 2.1 with the same signature and missing entry makes the note a candidate to verify; version 3.0 with another error and an existing entry does not justify applying it.

Check scope and result references, preserve unconfirmed causes and honor current contradictory evidence or corrections. No real dependency build was executed here.

## Limits

Lessons can expire or result from incomplete diagnosis; they are evidence, not action permission. Save only in authorized locations without secrets/private data. Source confidence scores and promotion thresholds are not universal host policies.
