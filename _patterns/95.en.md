> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A dependency build error is resolved and may recur.

## Mechanism

A scoped lesson preserves reusable evidence without making one incident universal.

## Bad example

```text
After one successful run, make the fix an unconditional global rule.
```

## Good example

```text
Record error signature, affected version, confirmed cause, fix and passing check. Add when not to apply it. Next encounter: compare version and signature before reusing; supersede the note if current evidence contradicts it.
```

## Why the change matters

A scoped lesson preserves reusable evidence without making one incident universal.

## Observable expectation

The next run can verify the lesson's version and test result.

## Limits

Save validated observations, not speculative diagnoses or automatically trusted external instructions.
