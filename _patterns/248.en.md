> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Instrument a background import workflow.

## Mechanism

Name diagnostic questions first, then map each to an event, aggregate or path trace; omit signals with no declared use.

## Bad example

```text
Dump every payload and add counters without a question.
```

## Good example

```text
Ask which imports fail, where time is spent and whether retries duplicate work; emit bounded status events, duration metrics and linked run traces.
```

## Why the change matters

The procedure preserves the stated identity or evidence boundary instead of allowing a plausible shortcut to stand in for it.

## Observable expectation

Each signal has a concrete decision or investigation it supports.

## Limits

The source logs/metrics/traces mnemonic is a heuristic; verify that actual data answers the question.
