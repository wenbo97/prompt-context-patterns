> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent is evaluated on diagnosing a fault in a repository fixture.

## Mechanism

Give it the realistic symptom and allowed fixture; keep gold labels and grader data outside its accessible environment, remove leftover trial state, and check its actual access paths.

## Bad example

```text
Store gold.json in the agent checkout and merely instruct it not to read the answer key.
```

## Good example

```text
Keep the gold file in the grader process outside the agent workspace; expose the same user-visible symptom as production.
```

## Why the change matters

A verbal prohibition cannot establish a hidden-answer boundary.

## Observable expectation

Accessible files, history, tools and trial leftovers can be inspected.

## Limits

Isolation depends on the actual sandbox and credentials; model memory or public copies may still reveal answers. A case testing retrieval needs enough obscurity to require that work.
