> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Evaluate two revisions of an incident-summary skill.

## Mechanism

Matched inputs and blinded labels reduce direct expectation cues.

## Bad example

```text
Show the evaluator which output is improved and ask whether it is better.
```

## Good example

```text
Run both versions on the same frozen incidents. Randomize output labels, conceal version identity and score factual preservation with one rubric. Allow ties; store judgments before decoding labels and repeat cases.
```

## Why the change matters

Matched inputs and blinded labels reduce direct expectation cues.

## Observable expectation

The result includes per-case judgments, label mapping and repeated-run variation.

## Limits

Blinding removes version cues, not all evaluator bias; report variation and ties.
