> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Package a pull-request review skill for a host that reads YAML frontmatter.

## Mechanism

A specific trigger distinguishes review from implementation.

## Bad example

```text
name: helper
description: Helps with things
```

## Good example

```text
---
name: pr-review
description: Review a requested PR diff for concrete correctness defects.
---
```

## Why the change matters

A specific trigger distinguishes review from implementation.

## Observable expectation

The host parses name and description; test a review request and an implementation request.

## Limits

Use only fields the host documents; metadata alone cannot enforce tool permissions.
