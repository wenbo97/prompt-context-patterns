> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Reuse a team's default project across issue-lookup sessions.

## Mechanism

Validation separates a reusable preference from expired or misplaced state.

## Bad example

```text
Ask the project name every time and save tokens beside it.
```

## Good example

```text
Read .config/issue-helper.json. Require schema_version and project; ask only for missing values. Store the project choice, not access tokens. Revalidate before using it in a new repository.
```

## Why the change matters

Validation separates a reusable preference from expired or misplaced state.

## Observable expectation

A valid file avoids duplicate questions; invalid fields trigger targeted setup.

## Limits

A saved preference is not standing permission for external writes.
