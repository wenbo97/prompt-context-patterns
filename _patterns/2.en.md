> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Fix empty-email validation in an existing service.

## Mechanism

Each later stage consumes the earlier stage's evidence.

## Bad example

```text
Fix empty-email validation, improve the service, and test it later.
```

## Good example

```text
1. Reproduce empty email returning 500.
2. Change validation only after reproducing.
3. Verify empty email returns 400 and valid email still succeeds.
```

## Why the change matters

Each later stage consumes the earlier stage's evidence.

## Observable expectation

Record the failing and passing commands and the regression result.

## Limits

Keep tiny tasks lightweight; a numbered plan does not itself prove success.
