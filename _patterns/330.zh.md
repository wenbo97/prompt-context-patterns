> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

两名必需审核者审发布说明，一人指出无来源 benchmark。

## 机制

将原规范及精确产物交隔离审核，必需结论取 AND，修有证据阻塞，再有限轮次重审新产物。

## Bad example

```text
一份 PASS 就够，或把 v1 的 PASS 与 v2 的另一 PASS 拼一起。
```

## Good example

```text
v2 继续阻塞，直至两人都按同一标准审 v2，且无来源主张解决。
```

## 差异说明

门槛不混产物版本，也不让一次必需审核抹去另一份。

## 可检查的结果

记录产物和 rubric 版本、各结论及有限修复结果。

## 适用边界

审核者会同错或误报，需核证；审核门槛提供证据，不提供部署授权。
