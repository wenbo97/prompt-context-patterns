> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A review needs an owner-routing table maintained outside the skill.

## Mechanism

An exact path plus read condition makes the dependency explicit.

## Bad example

```text
Find the routing information somewhere in the repository.
```

## Good example

```text
Before assigning an owner, read references/owners.md relative to this skill. It maps service IDs to teams. If the service is missing, report no match instead of inventing an owner.
```

## Why the change matters

An exact path plus read condition makes the dependency explicit.

## Observable expectation

The chosen owner cites a table row; absent entries stay absent.

## Limits

Check the referenced revision and path; a pointer can become stale.
