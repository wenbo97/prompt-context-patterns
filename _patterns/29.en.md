> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A newly introduced catalog search fails to find a known pattern.

## Mechanism

The request attaches feedback to a concrete failure instead of interrupting active work.

## Bad example

```text
Ask for a satisfaction survey after every search result.
```

## Good example

```text
After resolving the failed search, offer a brief bug report containing query, expected pattern and observed result. Ask at most once this session; record only feedback the user chooses to give.
```

## Why the change matters

The request attaches feedback to a concrete failure instead of interrupting active work.

## Observable expectation

One session produces at most one feedback request.

## Limits

User silence is neither approval nor a satisfaction signal.
