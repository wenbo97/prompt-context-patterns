> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A learning observer records tool events while analyzing its own recorded tool events.

## Mechanism

Carry an explicit automated-run marker across child execution, check it at the capture entry point before creating metadata or scheduling more analysis, and preserve legitimate human events.

## Bad example

```text
Capture the observer’s own reads/writes, then launch another observer to learn from them repeatedly.
```

## Good example

```text
Launch the observer with ECC_SKIP_OBSERVE=1; capture checks that marker before project metadata writes, so the child does not feed its own learning queue.
```

## Why the change matters

The feedback edge is removed before it generates recursive work.

## Observable expectation

The self-generated run adds no observations or lazy-start metadata; a regular authorized interactive run still records its event.

## Limits

A cooperative marker is not authentication or a safety boundary; test all producer paths and avoid excluding unrelated legitimate events by a broad name match.
