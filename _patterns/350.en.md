> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Add rate limiting to API endpoints in a codebase that calls its existing limiter “throttle.”

## Mechanism

Search broadly, assess each result against the task, list gaps, add discovered terminology, and stop at a bounded sufficient context set.

## Bad example

```text
Search “rate limit” once; report that no limiter exists and write a new one.
```

## Good example

```text
Search “rate limit”; inspect middleware references, discover “throttle,” retrieve throttle.ts and its router wiring, and stop when the ownership and call path are known.
```

## Why the change matters

The second query follows observed vocabulary and a named missing call path rather than repeating the initial query.

## Observable expectation

A reviewer can inspect the final relevant paths, gap log, and stopping condition.

## Limits

Use a fixed retrieval budget; retain unresolved gaps. Source relevance numbers are illustrative, not calibrated probabilities.
