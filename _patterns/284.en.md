> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Write instructions for a flexible review and a fragile migration.

## Mechanism

Permit judgment where multiple safe approaches exist; provide configurable procedure for bounded variation; pin sequence/arguments when a verified narrow path is required.

## Bad example

```text
Use the same rigid command recipe for every task, or leave a destructive migration as do what seems best.
```

## Good example

```text
Allow evidence-based review judgment; for the verified migration use its documented exact command and validation/backup preconditions.
```

## Why the change matters

The allowed degrees of freedom match the actual operation rather than an arbitrary style preference.

## Observable expectation

Instructions identify which choices are flexible and which are contract-bound.

## Limits

Exactness cannot authorize unsafe execution or replace current tool-contract checks; do not invent universal safe defaults.
