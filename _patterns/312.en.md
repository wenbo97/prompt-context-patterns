> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Test whether undo semantics feel right.

## Mechanism

Distinguish logic/state from visual uncertainty; minimize setup, use scratch state and preserve the question and verdict.

## Bad example

```text
Build a polished production-style UI with a real database.
```

## Good example

```text
Make one in-memory interactive state demo, show state after each action, exercise conflicting edits and capture the undo verdict.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

The experiment answers the declared question with visible transitions.

## Limits

A prototype verdict does not establish production robustness.
