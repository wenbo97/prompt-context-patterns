> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Package a destructive repo-cleanup capability alongside read-only helpers.

## Mechanism

Invocation choice trades automatic discovery against deliberate human selection.

## Bad example

```text
Expose every capability with an always-triggering description.
```

## Good example

```text
Read-only source lookup can be discoverable by a narrow description. Destructive cleanup is user-invoked if the host supports that flag; its body still requires scoped authorization. Document how the user finds it and what it changes.
```

## Why the change matters

Invocation choice trades automatic discovery against deliberate human selection.

## Observable expectation

Ordinary lookup requests do not silently activate destructive cleanup.

## Limits

Invocation flags are host-specific and do not replace tool enforcement or approval.
