> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Decide whether to keep a one-method parser wrapper.

## Mechanism

Trace caller obligations after hypothetical deletion; retain hidden reusable behavior and collapse pure pass-through layers.

## Bad example

```text
Keep it because extra layers are cleaner.
```

## Good example

```text
Compare callers with and without the wrapper; collapse it if nothing is hidden, retain it if each caller would duplicate validation and ordering rules.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

The recommendation cites an actual responsibility rather than layer count.

## Limits

Hypothetical deletion is a reasoning aid; dependencies and compatibility still constrain actual removal.
