> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Hand a palette to an implementation agent.

## Mechanism

Pair a human description with a machine-usable value and where it applies, then use the same vocabulary throughout the handoff.

## Bad example

```text
Use dark text and a nice blue.
```

## Good example

```text
Primary ink #18181B for body text; action blue #2563EB for primary buttons and focus indication; preserve these roles across screens.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

The receiver can distinguish identity, value and intended usage.

## Limits

Exact values require rendering/contrast checks; a token name alone does not validate usability.
