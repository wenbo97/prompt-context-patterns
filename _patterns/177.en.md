> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A source analyzer may exist but lack the parser for this project's language.

## Mechanism

A real probe tests the needed behavior instead of mere installation.

## Bad example

```text
command -v analyzer succeeded, so schedule the full analysis.
```

## Good example

```text
Check the binary, then run its documented read-only syntax probe on one representative project file. Inspect exit code and parser diagnostics. If unsupported, record capability unavailable and choose a documented alternative.
```

## Why the change matters

A real probe tests the needed behavior instead of mere installation.

## Observable expectation

The selected analyzer demonstrably parses the representative file.

## Limits

Choose a non-mutating probe; one file does not establish full-language or project coverage.
