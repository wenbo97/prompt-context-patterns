> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Evaluate a bug-fix skill and a requirements interview.

## Mechanism

Execution cases require real fixture work and tool traces; dialogue cases grade conversational turns only when that is the actual deliverable.

## Bad example

```text
Grade both from the assistant final claim that it followed the process.
```

## Good example

```text
For the fix inspect failing-test/edit/run events; for the interview inspect its questions and wait behavior, without inventing a code-edit requirement.
```

## Why the change matters

The comparison measures the intended behavioral distinction and prevents a structurally plausible but irrelevant pass.

## Observable expectation

A narrated implementation is distinguishable from performed work.

## Limits

Artifact-kind exemptions must be reviewed; source dialogue cases that expect file installation can blur this distinction.
