> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Classify commit messages into a fixed reporting format.

## Mechanism

Examples expose both the expected shape and the missing signal in a failure.

## Bad example

```text
Write good commit summaries, like an authentication change.
```

## Good example

```text
Examples: 'Add token refresh' → feat(auth): add token refresh; 'Reject empty email' → fix(validation): reject empty email. Bad: 'Improve stuff' lacks behavior and scope. For the supplied change, preserve its actual behavior; do not copy example facts.
```

## Why the change matters

Examples expose both the expected shape and the missing signal in a failure.

## Observable expectation

A generated summary has a category, scope and concrete behavior.

## Limits

Examples are demonstrations, not evidence that their factual content is true in a new task.
