> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

检查脏工作区后准备 git commit。

## 具体做法

同一稳定状态的读取可独立；commit 依赖暂存 index。

## 反例

```text
并发运行 git add、git commit、git status。
```

## 改进写法

```text
并行读取 status、diff、近期提交风格。选定请求文件后，依次暂存、提交、检查最终 status；构造提交前检查全部读取结果。
```

## 为什么这样改

同一稳定状态的读取可独立；commit 依赖暂存 index。

## 如何验证

提交包含所选暂存修改，之后才检查 status。

## 适用边界

并行读取要求输入稳定；所有依赖修改与检查保持顺序。
