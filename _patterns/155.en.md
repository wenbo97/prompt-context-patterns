## Use case

A registry plans to retire an old review skill.

## Mechanism

Lifecycle state separates migration time from removal and names the next supported path.

## Bad example

```text
Set deprecated=true and remove the old entry immediately.
```

## Good example

```text
Proposed registry contract: active → deprecated → retired. Deprecation includes reason, supported-until date and replacement ID. Keep an alias page for installed consumers; verify links and migration instructions before retirement.
```

## Why the change matters

Lifecycle state separates migration time from removal and names the next supported path.

## Observable expectation

Old consumers can find the replacement without guessing a new identifier.

## Limits

The contract is illustrative; verify the actual registry supports any lifecycle fields used. Keep the retired identity, rationale, replacement and any revisit condition discoverable so a later agent does not recreate a deliberately removed capability.
