> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A skill pack shortens each entry file but forces the same long reference to be read at startup.

## Mechanism

Inventory discovery metadata, full front matter and invocation content including mandatory references. Count each ledger with a declared tokenizer or labelled estimate; compare complete consumed inputs rather than entry-file size alone.

## Bad example

```text
Our entry file fell from 20 KB to 2 KB. Claim a 90% context saving even though every invocation must read the 18 KB reference.
```

## Good example

```text
Audit the same skill pack before and after. Report discovery metadata, full front matter and per-invocation eager content as separate ledgers, including the mandatory 18 KB reference. Label byte-based token estimates. The entry is shorter, but do not claim an eager-context reduction unless the complete loaded total fell.
```

## Why the change matters

Moving text into a forced reference changes its location without removing it from the model input.

## Observable expectation

The audit shows which sessions pay each cost and exposes any unchanged eager total.

## Limits

Actual loading varies by host and runtime. Estimates are not tokenizer measurements, and smaller context alone does not prove equal task quality.
