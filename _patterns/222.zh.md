> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

检索到的上传工具返回 schemaRef，没有内联字段。

## 机制

展开引用，检查必填字段及类型，再构造并校验参数。

## Bad example

```text
把 schemaRef 当成完整定义，猜测 file 和 content 字段。
```

## Good example

```text
展开 schemaRef，检查实际文件对象与格式字段，再提交受支持字段。
```

## 差异说明

引用只指向信息，本身不包含契约内容。

## 可检查的结果

执行参数可与本流程加载的完整 schema 一一核对。

## 适用边界

只展开本任务相关的 schema；契约变化后重新获取。
