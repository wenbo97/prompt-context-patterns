> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Set a quality gate on a legacy project.

## Mechanism

Record metric value, measurement conditions, allowed direction and tolerance; compare equivalent runs and update improved baselines.

## Bad example

```text
Demand an invented80% threshold the inherited project cannot pass.
```

## Good example

```text
Measure the current changed-line coverage, record the baseline/command and require no comparable regression; define separate improvement work.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

The gate detects deterioration without pretending the inherited state is already ideal.

## Limits

Changing denominator/workload can invalidate comparison; a ratchet is not proof of sufficient absolute quality.
