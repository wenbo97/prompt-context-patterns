> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A connector search returns no issue-creation action for the requested service.

## Mechanism

The fallback keeps useful work distinct from fabricated execution.

## Bad example

```text
Invent create_issue and report the ticket was created.
```

## Good example

```text
Record that discovery returned no supported create action. Do not call a guessed slug. Prepare a local ticket draft if permitted, label it not submitted, and identify the documented setup or alternative the user can use.
```

## Why the change matters

The fallback keeps useful work distinct from fabricated execution.

## Observable expectation

No external ticket ID is claimed without an actual creation response.

## Limits

A frozen repository's availability note is not proof of today's connector capabilities.
