> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

审核每个目录项，包括合并和撤下项。

## 机制

判定条件防止过早成功，清单界定必须检查的范围。

## Bad example

```text
博客看起来改善、示例够多就完成。
```

## Good example

```text
完成意味着每个原 ID 有且仅有一个 active/merged/removed 决定，所有有效项有双语字段，引用有效，没有未审项。运行覆盖检查，明确列出排除页面。
```

## 差异说明

判定条件防止过早成功，清单界定必须检查的范围。

## 可检查的结果

最终报告含零未审 ID 与校验结果。

## 适用边界

穷尽清单仅限声明语料，不暗示全球全部覆盖。 摘要审计应从每项独立来源义务及必要补救出发，逐项映射到保留文本，并单独检查声称的处置。计数或词语一致本身不证明语义覆盖。
