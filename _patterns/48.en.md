> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Run checks for blocking data-loss risks and advisory documentation gaps.

## Mechanism

Each rule carries both its predicate and consequence.

## Bad example

```text
Fail the review whenever any concern is mentioned.
```

## Good example

```text
rules: [{id: SAFE-1, check: rollback_present, on_fail: block}, {id: DOC-1, check: summary_present, on_fail: advise}]. Record rule revision and evidence; unknown evidence returns needs_review, not pass.
```

## Why the change matters

Each rule carries both its predicate and consequence.

## Observable expectation

A missing summary produces advice; a missing required rollback blocks.

## Limits

Rule data needs validation and a documented authority; YAML is not intrinsically enforceable.
