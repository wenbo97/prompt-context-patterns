> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A stop hook resumes an unfinished local repair task.

## Mechanism

Exit states and external evaluation prevent one convenient completion string from controlling the loop.

## Bad example

```text
Always resume until the agent writes DONE, regardless of evidence or budget.
```

## Good example

```text
The hook reads a structured state file. Complete requires the named acceptance checks; blocked records missing input; exhausted stops at three rounds. A trusted controller evaluates exits and never converts a stalled run into complete.
```

## Why the change matters

Exit states and external evaluation prevent one convenient completion string from controlling the loop.

## Observable expectation

Blocked and exhausted runs terminate with preserved unresolved work.

## Limits

External stop logic and a budget must exist; a prompt cannot enforce its own loop termination.
