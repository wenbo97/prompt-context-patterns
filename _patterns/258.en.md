> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent response contains readable text, a tool-call identity and an opaque continuation block.

## Mechanism

Store the full envelope with typed blocks and matching identities; extract text for display while returning the unchanged required state on continuation.

## Bad example

```text
Save only the first text block and rebuild the next request from its prose summary.
```

## Good example

```text
Display the text, but retain the raw tool and opaque blocks and bind the tool result to the original call identity.
```

## Why the change matters

Display text is not the complete operational state of a protocol.

## Observable expectation

The stored envelope, typed dispatch and result-to-call identity can be checked.

## Limits

Retention, replay and signature rules are host-specific. Do not fabricate or decrypt opaque fields; apply data-handling rules and verify which transformations are allowed.
