> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

分别评审 API 正确性与无障碍问题。

## 机制

职责分离和共同版本使结果可比较。

## Bad example

```text
启动许多 agent，让它们审查所有内容并投票判断错误。
```

## Good example

```text
一个只读 agent 检查 API 正确性，另一个检查无障碍；两者用同一固定版本与明确输入。按触发条件和位置合并，核查证据，保留分歧，不按票数推断真伪。
```

## 差异说明

职责分离和共同版本使结果可比较。

## 可检查的结果

每个采纳的问题有代码证据，不依赖赞同票数。

## 适用边界

独立工作不足以抵消协调成本时用单 agent；强制明确修改归属。
