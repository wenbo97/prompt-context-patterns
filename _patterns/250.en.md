> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review code containing backticks and command-substitution syntax.

## Mechanism

Write the full artifact/contract prompt to a file and feed stdin; verify the tool and use a read-only execution boundary.

## Bad example

```text
Interpolate the source directly into a shell command argument.
```

## Good example

```text
Write the exact prompt to a file, pass the file on stdin to the verified read-only reviewer, and retain the invocation/result provenance.
```

## Why the change matters

The contract names which evidence may be reused and which decision remains unresolved, so the result can be checked.

## Observable expectation

Shell metacharacters in the artifact do not become shell instructions.

## Limits

A read-only wrapper limits filesystem effects, not all prompt-injection or external-data risk; host flags must be verified.
