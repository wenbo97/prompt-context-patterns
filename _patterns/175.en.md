> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A security scanner is installed but cannot authenticate to this project.

## Mechanism

Presence is not execution, and execution is not success unless results are inspected.

## Bad example

```text
The scanner is installed, so report security coverage complete.
```

## Good example

```text
Record present=yes, runnable=no, ran=no, reason=authentication unavailable. Keep static findings separate from scanner findings. Only attach scanner coverage when a recorded run at the audited revision produced evidence.
```

## Why the change matters

Presence is not execution, and execution is not success unless results are inspected.

## Observable expectation

The report cannot count an unrun scanner as completed coverage.

## Limits

A successful invocation may still have skipped files; record actual scope and output.
