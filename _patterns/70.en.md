> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Continue a catalog migration after the conversation is compacted.

## Mechanism

A durable record carries progress beyond one conversation and detects stale artifacts.

## Bad example

```text
Remember which patterns you finished and start again if unsure.
```

## Good example

```text
At each batch, record catalog revision, completed IDs, artifacts, validation command/result and next ID in progress.json. On resume, read it and verify artifact hashes before skipping completed batches.
```

## Why the change matters

A durable record carries progress beyond one conversation and detects stale artifacts.

## Observable expectation

The resumed run neither repeats verified batches nor trusts mismatched hashes.

## Limits

The ledger is evidence to verify, not infallible memory; use atomic updates for shared writers.
