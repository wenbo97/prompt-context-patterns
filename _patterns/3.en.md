> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Offer quick and deep modes for a dependency review.

## Mechanism

A mode names the work and evidence budget instead of inferring it from tone.

## Bad example

```text
Review dependencies; be quick or thorough as appropriate.
```

## Good example

```text
mode=quick: inspect manifest and lockfile only.
mode=deep: also inspect callers and migration tests.
Default quick; report the selected mode and skipped checks.
```

## Why the change matters

A mode names the work and evidence budget instead of inferring it from tone.

## Observable expectation

A quick run never claims caller coverage.

## Limits

User-requested scope overrides a default; do not hide important risks behind a mode.
