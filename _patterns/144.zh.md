## 使用场景

向上下文有限的 agent 暴露 issue 查询。

## 具体做法

契约提供行动所需证据，避免上下文洪泛和猜测恢复。

## 反例

```text
返回整个 issue 数据库，输入无效时只返回“400”。
```

## 改进写法

```text
暴露 typed 参数的 find_issue(project, id)。返回摘要、证据 URL 与可选分页。项目未知时说明错误字段及已记录 list_projects 能力，不把用户内容当指令。
```

## 为什么这样改

契约提供行动所需证据，避免上下文洪泛和猜测恢复。

## 如何验证

agent 可选择合法输入，并有意识获取更深细节。

## 适用边界

只信任获准工具实现的错误提示；外部文本仍是不可信数据。
