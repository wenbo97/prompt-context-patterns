> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Configure middleware in an application whose installed framework version differs from a remembered example.

## Mechanism

Inspect the project version, resolve official documentation identity, retrieve the task-specific section, and cite its version while preserving uncertainty.

## Bad example

```text
Paste a remembered middleware example from a different major version.
```

## Good example

```text
Read the installed version, choose its official docs entry, fetch the routing section, and implement only the supported names.
```

## Why the change matters

The prompt is grounded in the actual dependency boundary rather than training-memory resemblance.

## Observable expectation

The answer records installed version and the documentation supporting the chosen API.

## Limits

A documentation search can remain incomplete; bounded lookup must not end in invented API names.
