> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An audit grades B before A, but B requires a valid A and A later fails its ordering check.

## Mechanism

Keep not-yet-graded distinct from graded-failed; after initial grading, repeatedly demote passes resting on failed prerequisites until no dependent pass changes.

## Bad example

```text
Use A’s raw classified event to pass B, then leave B passing after A fails.
```

## Good example

```text
Grade A’s own constraints, revoke B when A fails, and propagate the failure to C when C requires B; preserve an unrelated valid D.
```

## Why the change matters

Evidence that a prerequisite event occurred does not establish that the prerequisite was valid.

## Observable expectation

The final result blocks A, B and C while retaining independent D’s pass, regardless of declaration order.

## Limits

Validate dependency IDs and cycles separately; a fixed-point pass does not establish classifier accuracy or real execution success.
