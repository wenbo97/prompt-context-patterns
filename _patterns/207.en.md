> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Generate a video whose creation response returns job_id=J3.

## Mechanism

Save job ID, poll status within a task budget, retrieve output after completion, and report pending/failed states honestly.

## Bad example

```text
Publish the creation response as if the video already exists.
```

## Good example

```text
Save J3; poll until completed; then retrieve the video URL; if the budget expires report J3 as pending.
```

## Why the change matters

Job acceptance does not establish usable output.

## Observable expectation

The report contains terminal status and output, or a resumable pending job ID.

## Limits

Set bounded polling and cancellation policy; temporary output URLs may expire.
