> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Emit a migration check that another process parses.

## Mechanism

Enumerated states and aggregation rules remove hidden interpretation by consumers.

## Bad example

```text
Return a clear structured migration assessment.
```

## Good example

```text
Return JSON only: {status: PASS/FAIL/UNKNOWN, checks: [{name, observed, expected, result}]}. Any failed check gives FAIL; unknown evidence gives UNKNOWN unless a failure exists.
```

## Why the change matters

Enumerated states and aggregation rules remove hidden interpretation by consumers.

## Observable expectation

Parse the JSON and verify status agrees with every check.

## Limits

A prompt-specified shape still needs schema validation before machine use.
