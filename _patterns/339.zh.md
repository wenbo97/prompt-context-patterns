> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

README、架构图和周报重复同一迁移状态。

## 具体做法

确定状态事实的权威归属，架构规则归其自身文档，其他处改为链接。

## 反例

```text
README 已完成，架构图仍阻塞，周报第三种说法。
```

## 改进写法

```text
状态记录写当前迁移状态，设计文档写架构约束，README 链接两者。
```

## 为什么这样改

同一事实的多个副本不再争夺当前权威。

## 如何验证

读者可从概览追到明确的权威记录与当前状态。

## 适用边界

不同受众可需摘要；标为派生并维护时效，不是禁止所有复述。
