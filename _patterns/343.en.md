> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A release workflow tests archiveA, then rebuilds archiveB before publishing the same version.

## Mechanism

Pack once from the intended revision, record its digest, test that archive, publish the same bytes to a staging lane and compare public integrity before promotion.

## Bad example

```text
Treat green source tests as proof of rebuilt archiveB and announce publication without checking the served artifact.
```

## Good example

```text
Test archiveA, stage archiveA, compare its digest to the served version and promote only that verified identity; report a mismatch as blocked.
```

## Why the change matters

The evidence remains attached to the artifact users actually receive.

## Observable expectation

The release record links source revision, tested archive digest, published integrity and promotion/readback results.

## Limits

Digest agreement proves byte identity, not correctness or authorization; signing, required checks and release permissions remain separate gates.
