> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Debug a validator that intermittently accepts blank emails.

## Mechanism

A concrete feedback signal lets hypotheses predict an observable result.

## Bad example

```text
Read many files, guess a root cause and patch it without reproducing.
```

## Good example

```text
Build one command that supplies blank-email fixtures and asserts rejection. Run it and capture the actual failure; for a flake pin seeds or record reproduction rate. Only then form falsifiable hypotheses and rerun the same signal after each change.
```

## Why the change matters

A concrete feedback signal lets hypotheses predict an observable result.

## Observable expectation

The recorded command fails on the reported symptom and passes after the relevant fix.

## Limits

When reproduction is impossible, report access or evidence gaps; do not claim a diagnosis by intuition.
