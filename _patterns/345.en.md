> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Add a connector to a legacy project with inconsistent old and new layouts.

## Mechanism

Compare current exemplars across file anatomy, state flow, infrastructure and errors; resolve meaningful conflicts and cite the chosen model.

## Bad example

```text
Copy the oldest connector wholesale, including obsolete error handling.
```

## Good example

```text
Cite current connector A for registration and B for retry behavior; state the old layout is superseded and flag its bug rather than reproduce it.
```

## Why the change matters

Pointers show the convention’s actual mechanism and distinguish evolution from accidental inconsistency.

## Observable expectation

The change can be reviewed against named exemplar paths and concrete rules.

## Limits

Popularity does not prove correctness; never transplant bugs merely to match style.
