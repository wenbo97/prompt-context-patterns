> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Open a report on Windows and Linux with different launch tools.

## Mechanism

Detection selects an adapter with a declared fallback instead of guessing a command.

## Bad example

```text
Use xdg-open report.html on every machine.
```

## Good example

```text
Detect the OS. Windows: use the documented PowerShell opener; Linux: use xdg-open only if available. Unsupported headless target: return the absolute file path. Report any feature loss.
```

## Why the change matters

Detection selects an adapter with a declared fallback instead of guessing a command.

## Observable expectation

An unsupported target still receives a usable report path.

## Limits

Verify installed capabilities; an OS name alone does not prove command availability.
