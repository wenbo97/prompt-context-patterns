> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Start a test server and reliably stop it after browser checks.

## Mechanism

A stable interface offloads lifecycle details to code and removes guessed flags.

## Bad example

```text
Reimplement the server lifecycle from memory inside the prompt.
```

## Good example

```text
For the approved scripts/with_server.py helper, inspect --help first. Use its documented command, port and readiness options for the requested test. Capture exit status and logs; investigate failures rather than editing the helper blindly.
```

## Why the change matters

A stable interface offloads lifecycle details to code and removes guessed flags.

## Observable expectation

Server readiness and cleanup are observed in the helper's result.

## Limits

Inspect untrusted executables before even running --help; trusted black-box use is not blanket trust.
