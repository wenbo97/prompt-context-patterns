> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

One worker adds clearLayers while another wires its caller.

## Mechanism

A shared contract exposes inter-task drift before integration.

## Bad example

```text
Implement the cleaner; the caller can guess its signature later.
```

## Good example

```text
Task A produces clearLayers(layerIds: string[]): Promise<void>. Task B consumes exactly that exported signature and awaits it. Both briefs cite the same interface artifact; validate import, argument and return compatibility.
```

## Why the change matters

A shared contract exposes inter-task drift before integration.

## Observable expectation

The consumer compiles against the producer's exact exported interface.

## Limits

An interface contract must be versioned and updated for agreed changes, not frozen against all evolution.
