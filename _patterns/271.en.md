> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A lint pass finds “Use this skill” in both metadata and an instruction body.

## Mechanism

Determine which consumer sees each field and when; keep routing intent in trigger metadata, accurate mechanics in tool contracts and the workflow in its loaded playbook.

## Bad example

```text
Delete every imperative occurrence because the same phrase appears in a keyword blacklist.
```

## Good example

```text
Keep the metadata’s scope trigger, remove an unrelated upsell from the tool return contract, and retain the task workflow in the skill body.
```

## Why the change matters

Identical words can serve different control roles at different load boundaries.

## Observable expectation

Each field has a named consumer, loading stage and operational purpose.

## Limits

Host routing behavior must be tested. Moving a sentence can change authority or availability; do not apply source model-superiority claims or arbitrary sentence-count rules as facts.
