> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent emits review.json for a publishing script.

## Mechanism

Execution replaces a model's format assurance with a checkable result.

## Bad example

```text
Say 'schema passed' after looking at the JSON.
```

## Good example

```text
Run the supplied JSON Schema validator on review.json. Accept only exit 0 and its recorded diagnostics. Repair named violations and retry within two attempts; if still invalid, do not publish.
```

## Why the change matters

Execution replaces a model's format assurance with a checkable result.

## Observable expectation

The consumed file is exactly the file whose validation result was recorded.

## Limits

Schema success checks shape, not truth, accessibility or complete behavioral correctness.
