> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A review benchmark adds an omitted factual-accuracy criterion after several rounds.

## Mechanism

Version the new criterion, regrade frozen outputs for baseline and all candidates, retain old-versus-new comparisons, and reconsider the winner if rankings change.

## Bad example

```text
Score only the latest candidate with the new criterion and compare it to the old baseline number.
```

## Good example

```text
Regrade the same saved outputs from every round with the new criterion, publish both grading versions, and reassess the earlier recommendation.
```

## Why the change matters

A change in measurement is separated from a change in the generated artifact.

## Observable expectation

Criterion versions, fixed output identities and ranking changes can be checked.

## Limits

Stored outputs may omit required evidence. Model judges add variance and cost; if the original search optimized the wrong signal, regrading alone does not undo that selection history.
