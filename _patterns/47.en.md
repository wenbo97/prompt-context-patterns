> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Review a cache-backed getUser call that may return null.

## Mechanism

Concrete propagation shows why the code fails rather than merely naming a rule.

## Bad example

```text
Missing null check; violates best practices. Add validation.
```

## Good example

```text
On cache miss, getUser returns null at cache.ts:18; profile.ts:42 reads user.email without handling it. Show this path, the cache-miss input and the resulting TypeError. Treat author justifications as claims to verify.
```

## Why the change matters

Concrete propagation shows why the code fails rather than merely naming a rule.

## Observable expectation

Another reviewer can follow the cited path and evaluate the claimed consequence.

## Limits

If a trigger or assumption is unknown, state the gap instead of asserting a confirmed defect.
