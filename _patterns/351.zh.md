> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

本地化 reviewer 保留主题和严重级别，却省略原文的证据门槛、零发现也可通过的规则、停止条件或报告证据字段。

## 机制

逐条抽取原文控制语句：所需证据、允许动作、停止／升级触发条件、评分或验收阈值、报告字段。将译文对应项标为保留、省略、弱化或强化，并按相同条件核对示例。

## Bad example

```text
标题和术语看似对应，便判定译文语义等价，即使严重问题不再要求证据。
```

## Good example

```text
制作逐项双语控制表并记录原文与译文定位。单列缺失或弱化的门槛，对照最终输出契约；在修正或明确接受每项实质差异前，不宣称语义一致。
```

## 差异说明

即使译文易读且技术名称未变，安全、证据或评估门槛的消失仍会改变 agent 的操作行为。

## 可检查的结果

审查者可以指出每项实质控制差异及其影响，且本地化指令保留已约定的停止、取证和报告行为。

## 适用边界

这是文档对照，不证明运行时强制执行或实际效果。机器标识符／schema／路径完整性应另行检查。不得把固定版本的技术栈、版本或 API 示例当作当前产品事实。
