> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Build a web surface inspired by a native material.

## Mechanism

Use authoritative packages when required; otherwise label the visual inspiration and approximation without claiming official API status.

## Bad example

```text
Call custom CSS the official native material package.
```

## Good example

```text
Describe the effect as a web approximation inspired by the native material and cite the platform documentation separately from the implementation.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

The receiver knows what is official evidence and what the project constructed.

## Limits

The source particular platform/package claims are frozen observations; verify them before relying on present API availability.
