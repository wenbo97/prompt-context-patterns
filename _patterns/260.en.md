> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A structured-output host accepts number types but does not enforce the owner’s nonnegative-price constraint.

## Mechanism

Maintain the original validator, derive a compatible wire schema, and validate the returned data against every removed constraint before downstream use.

## Bad example

```text
Trust the host’s strict-schema label after dropping the minimum-price constraint.
```

## Good example

```text
Send the supported schema projection, then reject a negative price with the original validator before creating the quote.
```

## Why the change matters

Transport compatibility does not imply the full policy was enforced.

## Observable expectation

The original constraints, omitted wire facets and final validation result can be compared.

## Limits

The host’s actual supported subset must be verified. Full schema validation still does not prove source truth, authorization or semantic suitability.
