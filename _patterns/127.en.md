> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Prepare a git commit after inspecting a dirty worktree.

## Mechanism

Only reads of the same stable state are independent; commit consumes the staged index.

## Bad example

```text
Run git add, git commit and git status concurrently.
```

## Good example

```text
Read status, diff and recent commit style in parallel. Select the requested files, then stage, commit and inspect final status sequentially. Inspect all read results before constructing the commit.
```

## Why the change matters

Only reads of the same stable state are independent; commit consumes the staged index.

## Observable expectation

The commit contains the selected staged changes and status is checked afterward.

## Limits

Parallel reads require stable inputs; all dependent mutations and their checks remain sequential.
