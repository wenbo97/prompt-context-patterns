> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A plan requires a test that asserts only that a mock was called.

## Mechanism

Spec compliance and quality are separate claims; one cannot erase the other.

## Bad example

```text
The plan asked for the mock assertion, so mark quality approved.
```

## Good example

```text
Report two axes: spec satisfied, quality gap because the test cannot catch the requested behavior. Cite the plan and test; label plan-mandated and explain the missing regression signal for the owner to adjudicate.
```

## Why the change matters

Spec compliance and quality are separate claims; one cannot erase the other.

## Observable expectation

The report retains both the satisfied requirement and its concrete defect.

## Limits

The owner resolves the spec conflict; reviewers must not silently rewrite approved scope.
