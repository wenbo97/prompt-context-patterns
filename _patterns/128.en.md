> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A long migration session approaches its context limit.

## Mechanism

Named durable fields survive a lossy summary better than an unbounded recollection.

## Bad example

```text
Summarize everything as 'migration mostly done' and continue from memory.
```

## Good example

```text
Save target revision, approved scope, completed batches, unresolved errors, attempt count and next check. Link source artifacts rather than copied logs. Resume by verifying revision and artifacts; preserve the user's corrections verbatim where material.
```

## Why the change matters

Named durable fields survive a lossy summary better than an unbounded recollection.

## Observable expectation

The resumed agent can identify remaining work and the current attempt count.

## Limits

Compaction is lossy; verify source artifacts and do not promise unlimited memory.
