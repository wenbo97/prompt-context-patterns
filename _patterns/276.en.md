> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A cost search skips a configuration using a measured profile from a different setting, then revises the prompt.

## Mechanism

Store the profile and context identity behind the decision, name the ordering assumptions, keep uncertain candidates deferred, and re-probe affected choices after recalibration or prompt changes.

## Bad example

```text
Permanently discard the configuration because one mismatched cost projection looked unfavorable.
```

## Good example

```text
Mark it deferred with the projection basis; after the prompt changes, use a matching profile and a bounded re-probe before ruling it out.
```

## Why the change matters

A contextual estimate is not a timeless verdict about an unmeasured candidate.

## Observable expectation

The deferred list, decision prerequisites and reopening trigger are inspectable.

## Limits

Pruning can still miss a winner if ordering or projection assumptions fail. The source’s model/effort monotonicity and numeric error bands are unverified workload claims; this method does not guarantee a globally cheapest choice.
