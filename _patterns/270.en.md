> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A router description is revised from labeled training failures while candidate versions are compared on reserved queries.

## Mechanism

Pass only training cases and history to the reviser; use the reserved results for candidate selection, label that set validation, and reserve a fresh final test for an unbiased final estimate.

## Bad example

```text
Feed the reserved failures back into every rewrite and call the best reserved score an untouched test result.
```

## Good example

```text
Hide reserved fields from revision history; select the description on validation and report final performance on new cases.
```

## Why the change matters

Separating feedback channels makes direct case leakage visible and avoids mislabeling adaptive selection as final testing.

## Observable expectation

The revision prompt excludes reserved records; selection and final-test identities are recorded.

## Limits

The source implements withheld revision fields but selects repeatedly on its “test” set, so its score is validation, not an independent final estimate. Split ratios and repeat counts require task-specific calibration. Static stored thresholds and baseline scores are recorded artifacts, not fresh evaluation results. Held-out examples must not become revision feedback, and a provisional gate remains provisional when independent human judgment is missing.
