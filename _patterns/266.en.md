> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Evaluate a repository bug-fix agent.

## Mechanism

Start each trial in an isolated fixture, run hidden behavioral checks on the resulting diff and state, detect no-op success claims, and inspect process evidence only for declared constraints.

## Bad example

```text
Pass the run because its transcript says the bug was fixed and tests passed.
```

## Good example

```text
Run the hidden boundary test on its final checkout, inspect the allowed-file diff, and fail a claimed fix that left the workspace unchanged.
```

## Why the change matters

Narrated success is separated from the observable result.

## Observable expectation

The resulting files, tests, effects and prohibited changes can be checked.

## Limits

A state oracle covers only its invariants; hidden tests and isolated environments can be incomplete. Taste dimensions may need independent human or judge review.
