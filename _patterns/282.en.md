> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Reject an empty email currently accepted by a form.

## Mechanism

Write the rejection assertion, observe the actual behavioral failure rather than setup error, implement the required rule and refactor only while the relevant checks remain green.

## Bad example

```text
Write a passing test around the current behavior after implementing the fix and call it a regression proof.
```

## Good example

```text
Assert empty email produces the required error; see it fail against the old form; add the rule; verify the same assertion passes and relevant existing behavior remains intact.
```

## Why the change matters

The failing run demonstrates sensitivity to the named defect.

## Observable expectation

The record contains expected RED, resulting GREEN and the code state each run covered.

## Limits

Test necessity depends on change risk; do not delete unrelated user work or pretend an import error is behavioral evidence.
