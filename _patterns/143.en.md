> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Apply a slide theme for a monochrome technical report.

## Mechanism

A named fallback avoids force-fitting while preserving the catalog as a useful default.

## Bad example

```text
Force the closest colorful catalog theme even if it violates the brief.
```

## Good example

```text
Inspect available theme previews. Use an existing theme only if monochrome and readability constraints fit. Otherwise create a minimal theme meeting those constraints, show its preview and record it separately from approved catalog themes.
```

## Why the change matters

A named fallback avoids force-fitting while preserving the catalog as a useful default.

## Observable expectation

The selected or generated theme satisfies the same stated constraints.

## Limits

Generated options are not automatically approved catalog entries; validate them before reuse.
