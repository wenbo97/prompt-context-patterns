> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Update a task named Budget in the Finance task list.

## Mechanism

List the intended parent, resolve task ID inside that parent and pass both identifiers.

## Bad example

```text
Use task_id=Budget and tasklist_id=Finance because those are their labels.
```

## Good example

```text
Resolve Finance to list L7; find Budget inside L7 as task T9; update using L7 and T9.
```

## Why the change matters

Labels are not IDs, and child IDs may depend on the parent.

## Observable expectation

The request includes IDs returned by lookup in the chosen parent.

## Limits

Disambiguate duplicate names; do not reuse IDs across workspaces.
