> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A catalog checker accepts a path and optional JSON output.

## Mechanism

Named arguments connect invocation syntax with outputs.

## Bad example

```text
Use the arguments to check whichever catalog the user means.
```

## Good example

```text
Usage: catalog-check <path> [--json].
Require an existing file; --json returns machine-readable findings.
Unknown flags or missing path: show usage and stop.
```

## Why the change matters

Named arguments connect invocation syntax with outputs.

## Observable expectation

Missing paths and unknown flags have explicit results.

## Limits

Argument injection syntax is host-specific; avoid guessing shell quoting or implicit flags.
