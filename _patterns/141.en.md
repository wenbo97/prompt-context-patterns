> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Read several independent logs and summarize failures after all reads finish.

## Mechanism

Executable data flow handles branches and error collection explicitly.

## Bad example

```text
Call nonexistent convenience APIs and hide errors in a generated loop.
```

## Good example

```text
Use the host's documented async read function for each approved path. Collect settled results, inspect every failure and pass only observed log data to the summary step. Sequence any dependent action after collection.
```

## Why the change matters

Executable data flow handles branches and error collection explicitly.

## Observable expectation

The summary accounts for every requested log, including failed reads.

## Limits

Use only documented APIs and inspect every error; orchestration code still requires authorization.
