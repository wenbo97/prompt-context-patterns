> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Obtain independent initial reviews of an authentication change.

## Mechanism

The boundary delays direct anchoring while keeping a controlled exchange channel.

## Bad example

```text
Let each reviewer read every other reviewer's draft before analyzing.
```

## Good example

```text
Reviewers A and B read the same revision and requirements, not each other's drafts. Save private notes separately. Exchange only finalized findings through shared/reports after both initial reviews finish.
```

## Why the change matters

The boundary delays direct anchoring while keeping a controlled exchange channel.

## Observable expectation

Initial reports are timestamped before cross-review access.

## Limits

Filesystem isolation must be enforced; separate folder names alone are not access control.
