> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Use an installed SaaS connector to retrieve a project issue.

## Mechanism

Discovery binds current capability and authentication to an actual schema.

## Bad example

```text
Call an imagined fetchIssue tool and assume the connection is active.
```

## Good example

```text
Search the connector's available issue-read actions. Read the returned schema and verify the account connection. Execute the documented read with the requested project and issue ID; if unavailable, report that gap instead of inventing a slug.
```

## Why the change matters

Discovery binds current capability and authentication to an actual schema.

## Observable expectation

The call names a discovered action and returns a real issue or an explicit failure.

## Limits

Connector-specific action names and connection states vary; never infer permission to send messages.
