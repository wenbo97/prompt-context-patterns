> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

两个独立服务都出现输入校验经验。

## 机制

比较兼容的触发与行动，保留证据和范围；存在相反纠正时降低置信或暂缓提升。

## Bad example

```text
React 约定只成功一次，就提升为全局规则。
```

## Good example

```text
比较两个服务的相同校验经验，确认通用性，带上两次观察和例外，提出更广规则。
```

## 差异说明

提升依据跨环境重复，不依据一次会话的自信。

## 可检查的结果

提案能指出贡献项目、观察和排除条件。

## 适用边界

来源阈值是运行配置，不是校准概率；正式政策仍走原有审核。
