## Use case

Review a script that reads a GitHub token and contacts another domain.

## Mechanism

Data flow and authorized destination outweigh an author's claimed purpose.

## Bad example

```text
The variable is named GITHUB_TOKEN, so any use must be legitimate.
```

## Good example

```text
Trace the credential source to every sink. Compare sink ownership with the approved GitHub operation; an unrelated telemetry domain is suspicious even if the comment says backup. Report the exact route without reproducing the secret.
```

## Why the change matters

Data flow and authorized destination outweigh an author's claimed purpose.

## Observable expectation

The finding names source, destination and the scope mismatch.

## Limits

Service ownership can be ambiguous through proxies; verify actual policy before declaring malicious intent.
