> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Triage a night-theme request.

## Mechanism

Match by concept, ask whether rationale still holds, and keep rejections distinct from built features and temporary deferrals.

## Bad example

```text
Close it because a vaguely similar issue is closed.
```

## Good example

```text
Find the durable theming rejection, show its rationale and ask whether it still holds; if the feature already exists, link implementation instead.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

Repeated concepts reuse reviewed rationale without false rejection inference.

## Limits

Similarity is a lead, not authority; maintainers may reconsider or distinguish the request.
