> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Document a project check command.

## Mechanism

Reference inspectable config/help for scripts and paths; document only unwritten conventions or expensive lookups.

## Bad example

```text
Copy the package scripts into several agent instruction files.
```

## Good example

```text
Tell the agent to read the check script in package.json; document separately why the integration fixture is required.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

Changing the script needs one authoritative edit.

## Limits

Cache a lookup when its cost is material, but identify its freshness obligation.
