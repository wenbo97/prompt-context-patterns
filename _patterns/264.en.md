> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

An agent repeatedly normalizes invoice currencies, totals rows and classifies unclear descriptions.

## Mechanism

Map call sites to responsibilities; implement fixed normalization and arithmetic in code, then send only ambiguous descriptions and needed context to the judgment step.

## Bad example

```text
Ask a model to repeat the same normalization and sum instructions separately for every row.
```

## Good example

```text
Normalize and sum in one deterministic pass; ask the model to classify the three ambiguous descriptions with their relevant evidence.
```

## Why the change matters

Mechanical invariants become inspectable while the actual judgment remains explicit.

## Observable expectation

The call-site map, deterministic outputs and remaining judgment inputs can be checked.

## Limits

A step is deterministic only if its policy and inputs are complete. Do not remove model judgment merely because inputs are structured; preserve error handling and source provenance.
