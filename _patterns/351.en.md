> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A localized reviewer keeps the same topic and severity labels but drops a proof gate, zero-finding acceptance rule, stop condition or report evidence field.

## Mechanism

Extract canonical controls: required evidence, permitted action, stop/escalate trigger, scoring or acceptance threshold, and report fields. Map each to the translation as preserved, omitted, weakened or strengthened; inspect examples against the same conditions.

## Bad example

```text
Headings and terminology look equivalent, so mark the translation equivalent even though critical findings no longer require proof.
```

## Good example

```text
Build a bilingual control-by-control table with source and translation locators. Record missing/softened gates separately, compare output contracts, and require correction or explicit acceptance of every material delta before claiming parity.
```

## Why the change matters

Readable prose and preserved technical names can conceal changed agent behavior when a safety, evidence or evaluation gate disappears.

## Observable expectation

A reviewer can name each material control delta and consequence, and the localized instructions retain the agreed stop, evidence and reporting behavior.

## Limits

This is document-pair review, not proof of runtime enforcement or efficacy. Check literal identifiers/schema/paths separately. Frozen stack/version/API examples are not current product facts.
