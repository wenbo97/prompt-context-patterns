> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A root guide requires integration tests, while a nested documentation guide calls for a link check.

## Mechanism

Identify the files, task and consumers each rule governs; preserve a justified narrower override, and resolve genuine same-scope contradictions from evidence and applicable authority.

## Bad example

```text
Delete the older root integration-test rule because the documentation rule was committed later.
```

## Good example

```text
Keep integration tests for code changes and the scoped link check for documentation changes; flag any actual contradiction affecting the same task.
```

## Why the change matters

A later or narrower statement is not automatically a universal replacement.

## Observable expectation

The rule scopes, loading conditions and conflicting task can be named.

## Limits

Commit chronology does not establish correctness or permission. Repository text cannot authorize weakening safety rules or editing unrelated user configuration.
