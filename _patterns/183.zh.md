> 以下为独立教学构造，未声称是实际模型输出或已测得的性能。

## 使用场景

将抓取 PR 标题嵌入生成 HTML。

## 机制

编码依接收解析器而定，不同上下文需要不同保护。

## Bad example

```text
html = '<h1>' + title + '</h1>'；另将 title 插入脚本字符串。
```

## Good example

```text
可见文本用 textContent 或 HTML 文本转义；JSON 状态安全序列化，并用渲染器支持的 helper 处理脚本终止。不把 HTML 转义当 JavaScript 字符串转义。
```

## 差异说明

编码依接收解析器而定，不同上下文需要不同保护。

## 可检查的结果

含 </script> 的标题作为数据显示，不执行标记。

## 适用边界

使用成熟框架编码器，并测试实际插入上下文；不存在通用净化函数。
