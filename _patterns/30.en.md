## Use case

A skill plugin may have an available update.

## Mechanism

Version comparison distinguishes freshness information from installation mutation.

## Bad example

```text
Fetch latest main and silently replace the installed plugin.
```

## Good example

```text
Read installed version; fetch signed release metadata with a short timeout. Compare using the supported version parser. Report update available or check unavailable; continue current work. An update is a separate authorized action.
```

## Why the change matters

Version comparison distinguishes freshness information from installation mutation.

## Observable expectation

A network failure leaves the installed version usable and is reported honestly.

## Limits

Version numbers alone do not establish compatibility or trust.
