> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Analyze request failure counts from logs with customer payloads.

## Mechanism

Pre-context reduction avoids relying solely on output-time redaction.

## Bad example

```text
Read all raw logs into context and redact the answer afterward.
```

## Good example

```text
Use an approved local aggregator to emit time bucket, error code and count only. Keep payloads and credentials outside model context. Review the returned schema for identifiers before analysis.
```

## Why the change matters

Pre-context reduction avoids relying solely on output-time redaction.

## Observable expectation

The model receives aggregate fields, not raw customer payloads.

## Limits

Pseudonyms and aggregates can still reveal identity; apply the actual handling policy.
