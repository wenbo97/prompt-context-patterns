> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Combine repository metadata with an optional issue-tracker lookup.

## Mechanism

Recovery depends on whether the missing data is essential.

## Bad example

```text
If anything fails, keep retrying until the report is complete.
```

## Good example

```text
Metadata missing: stop because the target is unknown. Issue lookup timeout: retry once, then report metadata with issue context unavailable. Authentication failure: report required access; do not invent issue details.
```

## Why the change matters

Recovery depends on whether the missing data is essential.

## Observable expectation

The report names failed inputs and never labels partial evidence complete.

## Limits

Retry writes only with idempotency protection; do not bypass authorization to recover.
