> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A prompt generates a retrieval index, and several query repetitions score that single generated index.

## Mechanism

Rebuild the unchanged baseline independently, score each build with the same query design, and preserve build identity in candidate comparisons; estimate uncertainty at the levels where randomness occurs.

## Bad example

```text
Rescore one baseline index many times and treat its tight score spread as the uncertainty of changing the index-building prompt.
```

## Good example

```text
Build several baseline indexes with the same prompt, score each, and compare candidate builds while keeping between-build and within-build variation visible.
```

## Why the change matters

Repeated scoring of one build cannot reveal variability from the generation step that was sampled only once.

## Observable expectation

Build identities, unchanged-prompt replicas and scores grouped by build can be inspected.

## Limits

Replicas must actually be independent at the intended level; shared caches or fixtures can couple them. The source’s example percentages and fixed replication counts are not verified guarantees.
