> 以下示例用于说明方法，不是模型实测结果。

## 使用场景

把一个 Skill 目录交给另一个 Agent 或复制到另一台设备上使用。

## 具体做法

列出必须引用的文件，按交付后的目录结构解析路径。缺少依赖时，一起打包或调整引用路径。

## 反例

```text
只复制 Skill 正文，../../references 指向的文件仍留在作者的代码目录。
```

## 改进写法

```text
把必需的参考文件一起交付。使用前，从接收方的 Skill 目录检查每个相对链接是否能打开。
```

## 为什么这样改

作者电脑上能找到文件，不代表接收方也能找到。按交付布局检查，能发现只存在于作者仓库中的依赖。

## 如何验证

从接收方的 Skill 目录出发，逐个打开必需的引用文件。

## 适用边界

文件存在不代表内容、版本或许可合适。可选资料缺失时，要有明确的替代做法。
