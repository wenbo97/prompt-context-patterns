> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Choose a speech model compatible with the requested output.

## Mechanism

List accessible models, inspect capability metadata and select a compatible identifier; handle missing identifiers explicitly.

## Bad example

```text
Use an old model name and assume every option supports speech.
```

## Good example

```text
List accessible models, filter for the speech capability, choose a returned identifier and use its supported parameters.
```

## Why the change matters

An identifier’s remembered existence does not establish current accessibility or feature support.

## Observable expectation

Selected identifier and required capability appear together in observed metadata.

## Limits

Metadata can change between discovery and execution; handle removal and refresh without fabricating substitutes.
