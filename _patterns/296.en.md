> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Add motion to a saved-item interaction.

## Mechanism

Require a reason tied to hierarchy, narrative, feedback or state change; omit effects with only decorative rationale.

## Bad example

```text
Animate every component because an animation library is available.
```

## Good example

```text
Animate the saved-item state transition so its new position is clear; keep the informational heading still.
```

## Why the change matters

The stated contract changes what the agent selects, preserves or verifies, and makes the difference inspectable.

## Observable expectation

Each selected effect has a reviewable purpose.

## Limits

A stated purpose does not prove the effect works; render it and inspect reduced-motion behavior.
