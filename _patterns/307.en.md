> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

Rename a shared configuration field across packages.

## Mechanism

Introduce both forms, migrate callers in bounded batches, and remove the old form only after all callers migrate.

## Bad example

```text
Rename the field once and let every package ticket fail until integration.
```

## Good example

```text
Add new field alongside old, migrate each package while both work, then remove the old field after a caller inventory reaches zero.
```

## Why the change matters

The contrast changes the decision procedure and makes its result inspectable.

## Observable expectation

Each staged batch has an explicit compatibility condition.

## Limits

If batches cannot pass alone, use a declared integration-only verification gate.
