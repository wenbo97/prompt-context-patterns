## Use case

Rename a published pattern without breaking its old URL.

## Mechanism

Stable identity permits editorial change without rewriting every external reference.

## Bad example

```text
Change the identifier and delete the old link everywhere.
```

## Good example

```text
Keep pattern ID 100 stable; update its bilingual display names. Map old slug to the same canonical ID. Validate no redirect cycle and ensure old anchors land on the new page or a clear compatibility entry.
```

## Why the change matters

Stable identity permits editorial change without rewriting every external reference.

## Observable expectation

Both old and new entrypoints resolve to the same active record.

## Limits

Never reuse a withdrawn identifier for an unrelated method; map merged entries to a deliberate target.
