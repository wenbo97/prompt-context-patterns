> Independent teaching constructions, not observed model outputs or measured performance.

## Use case

A SQL review skill overlaps with migration execution and general design.

## Mechanism

Boundary examples distinguish neighboring intents and provide handoffs.

## Bad example

```text
Use this skill for anything involving databases.
```

## Good example

```text
Use for reviewing supplied SQL migrations for locking and data-loss risks. For executing migrations, use the deployment workflow. For schema brainstorming without a migration, use design exploration.
```

## Why the change matters

Boundary examples distinguish neighboring intents and provide handoffs.

## Observable expectation

Review, execution and brainstorming requests route to different workflows.

## Limits

Provider or file-type detection is a hint; user-requested migration can legitimately cross providers.
