Tracked files: 1142; automation skills: 832; other skills: 32. Candidates: merged=19, active=21, rejected=1.

## Method and boundaries

Whole tracked inventory and normalized hashes; whole-body source family comparison with each alias/task substitution retained; semantic review of procedures and detailed contract/failure differences; low-level domain assets/syntax/implementation excluded explicitly. Family-equivalent files are analyzed, never falsely marked exact duplicates.

- No tool/provider calls or model experiments were run. Frozen source API specifics, performance claims and availability are observations, not verified current behavior.
- Document references were conceptually reviewed for routing, validation, preservation and bounded-context principles. Low-level document implementation/schema assets are excluded for domain-specific scope, not solely because of their restrictive license. No protected code or long examples are reproduced.
- Domain example outputs are illustrative, not measured results. Source archive/font/OOXML schema content is excluded with explicit reasons.

## Family findings

- **rube-base** (731): Discovery → ACTIVE connection → exact-schema execution; workflow session reuse; pagination continuation. App aliases add no new mechanism.
- **rube-enhanced** (26): Base plus prerequisite chaining, resource lookup before creation, nested failure awareness, auth recovery, backoff, schemaRef expansion and bulk workbench; variations are use-case labels.
- **domain-specific-workflows** (75): Each residual body was reviewed separately, including detailed workflows, a few scaffold-normalization exceptions, and unavailable placeholders. Differences include actual workflows, opaque identity types/scopes, parameter shape, pagination, temporal windows, quota and endpoint behavior. Methods are consolidated by mechanism, not toolkit name. Three files explicitly report unavailable native toolkit; several titles contain provider mismatches.
- **root-skills-and-references** (32): Writing, evidence-based feedback, reversible organization, art philosophy/refinement, named-reference routing, skill resources/packaging, tool design/evaluation, helper execution and artifact checks. Generic examples are independent teaching constructions; quantitative sample claims are not measured evidence.
