# Pattern Reference

This reference teaches reusable methods extracted from agent skills and distinguishes their usefulness from source provenance.

## Language

**Pattern**: A reusable mechanism for a specific class of task, with a concrete scenario, contrasting examples and explicit limits. A skill or API operation is not automatically one pattern.

**Observed source**: An immutable, located instance of a mechanism in a source file. It establishes occurrence, not the identity of its first inventor.

**Original provenance**: Evidence supporting the earliest attributable source of a method. It remains unknown when only later instances are located.

**Untraced pattern**: An editorially useful pattern whose source text has not been located. It carries a visible source-unconfirmed label.

**Editorial review**: Admission based on scenario, mechanism, contrast, observable result and boundaries. It is separate from measured model evaluation.

**Teaching construction**: An independently authored example illustrating a method. It is not presented as a historical source example or an observed model response.

**Merged pattern**: A retired identity whose mechanism is represented by one active entry. Its old entry points remain resolvable.

**Evaluation case**: A runnable experiment with its own identity and explicit links to patterns. Its identifier is not a pattern number.
