# 收录标准与原文说明

本站分别回答三个问题：方法是否适用于一个具体任务、原文实例在哪里，以及效果是否经过测量。

## 收录标准

每项按 0–2 分评阅：缺失得 0 分，部分满足或过于抽象得 1 分，具体完整得 2 分。收录要求总分至少 8/10，且使用场景、具体做法和有效对照三项各得 2 分。

| 标准 | 审核内容 |
| --- | --- |
| 使用场景 | 具体任务及已知条件 |
| 具体做法 | 读者能执行的指令或操作 |
| 有效对照 | 同一任务和事实下的反例与改进示例 |
| 可检查结果 | 能实际检查的结果或文件 |
| 适用边界 | 需要调整或停止的条件 |

这些分数衡量文章是否具体、完整，不代表模型成功率。相同做法会合并；说明不足或建议有误的条目会修改后重审，或从目录撤下。旧编号仍能通过迁移页找到对应内容。

## 来源状态

有原文链接的条目会列出仓库、固定 Git 版本、文件和行号。链接说明该做法在这份原文中出现过，不代表这里就是最早出处。

**来源未确认**表示尚未定位原文。有用的方法仍须达到相同编辑标准，才能带着标签保留。找到引用并不能豁免错误建议，示例和事实主张仍须独立审核。

## 教学示例与实验

每篇文章的对照示例都由本站编写，用于说明方法，并非实际模型输出。实际实验须说明样例、模型与配置、运行次数及可用输出。缺少原始输出的历史报告会明确标注，其数字不作为当前效果证据。
